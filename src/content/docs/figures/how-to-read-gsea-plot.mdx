GSEA plotは、あらかじめ定義した遺伝子セットが、ランキングの上位や下位に偏っているかを見るFigureです。

GSEAは Gene Set Enrichment Analysis の略です。差次的発現解析のように遺伝子を1つずつ見るだけでなく、経路や機能に属する遺伝子群が全体として偏っているかを見ます。

GSEA plotでは、横軸に遺伝子ランキング、縦軸にエンリッチメントスコアが示されることがあります。遺伝子セットに含まれる遺伝子がランキングのどこに多いかを確認します。

読み取るときは、どの比較のランキングか、遺伝子セット名、NES、FDR、leading edgeを確認します。経路名だけで結論を決めず、どの遺伝子が寄与しているかも見ます。

## よくある誤解

- GSEAの経路名だけで、機能が直接証明されたとは言えません。
- FDRやNESを確認せずに、曲線の形だけで判断してはいけません。
- 遺伝子セットの定義や比較条件によって結果の意味は変わります。
