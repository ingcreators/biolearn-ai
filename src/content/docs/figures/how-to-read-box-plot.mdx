箱ひげ図は、データの中央値、ばらつき、外れ値をまとめて見るためのFigureです。

箱ひげ図では、箱の中の線が中央値を表すことが多く、箱の上下は第1四分位数と第3四分位数を表します。箱の高さは、データの中央50%がどれくらい広がっているかを示します。

ひげの定義は論文や作図ソフトによって異なります。最小値・最大値を示す場合もあれば、四分位範囲の1.5倍までを示し、それより外側を外れ値として点で示す場合もあります。

箱ひげ図は、平均だけでは分かりにくい分布の形やばらつきを見るのに役立ちます。複数群を比べるときは、中央値の差だけでなく、分布の重なりや外れ値も確認します。

## なぜ重要か

生命科学論文では、発現量、細胞ごとの測定値、患者群の指標、スコアなどの分布を示すときに箱ひげ図が使われます。棒グラフより分布の情報が見えやすい一方で、定義を確認しないと誤読しやすい図でもあります。

## 英語表記と略語

| 日本語名   | 英語名              | 略語 |
| ---------- | ------------------- | ---- |
| 箱ひげ図   | box plot            | -    |
| 中央値     | median              | -    |
| 四分位範囲 | interquartile range | IQR  |
| 外れ値     | outlier             | -    |

## よくある誤解

- 箱の中央線は平均ではなく中央値であることが多いです。
- ひげの意味は図によって違うため、凡例やFigure legendを確認します。
- 中央値に差があっても、分布が大きく重なる場合は解釈に注意します。

## 重要用語

- 中央値: データを並べたとき中央に来る値。
- 四分位範囲: データの中央50%の範囲。
- ひげ: 箱から伸びる線。定義は図によって異なる。
- 外れ値: 分布から離れた値として表示される点。

## 前提に戻る

箱ひげ図は、[分布](/statistics/distribution/) と [平均と中央値](/statistics/mean-median/) を理解していると読みやすくなります。箱の中央線が平均ではなく中央値であることが多いため、代表値の違いを意識します。

群どうしを比べるときは、[n数とは何か](/statistics/sample-size/) に戻り、箱の中に何個の独立サンプルが含まれているかを確認します。点が多数あっても、独立したサンプル数が多いとは限りません。
