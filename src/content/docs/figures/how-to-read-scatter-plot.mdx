散布図は、2つの変数の関係を点の分布として見るFigureです。

散布図では、1つの点が1つのサンプル、細胞、遺伝子、患者、実験単位などを表します。横軸と縦軸にそれぞれ別の変数を置き、点がどのように広がるかを見ます。

右上がりの傾向があれば正の相関、右下がりなら負の相関と呼ばれることがあります。ただし、相関があることは、片方がもう片方の原因であることを直接示しません。

散布図を読むときは、軸の単位、対数表示、点の数、外れ値、グループ分け、近似線や相関係数の有無を確認します。点が多い場合でも、独立サンプル数が多いとは限らない点にも注意します。

## なぜ重要か

生命科学論文では、遺伝子発現どうしの関係、スコアと表現型、測定値の再現性、細胞ごとの特徴量などを示すときに散布図が使われます。分布を見ることで、平均値だけでは見えない構造に気づけます。

## 英語表記と略語

| 日本語名 | 英語名                  | 略語 |
| -------- | ----------------------- | ---- |
| 散布図   | scatter plot            | -    |
| 相関     | correlation             | -    |
| 外れ値   | outlier                 | -    |
| 相関係数 | correlation coefficient | r    |

## よくある誤解

- 相関があることは、因果関係を直接示すものではありません。
- 点が多いことと、独立サンプルが多いことは同じではありません。
- 近似線だけでなく、点の分布全体を見る必要があります。

## 重要用語

- 変数: 測定される値や特徴。
- 相関: 2つの変数が一緒に変化する傾向。
- 外れ値: 他の点から離れた値。
- 対数表示: 値の範囲が広いときに使われる軸表示。

## 前提に戻る

散布図を読むときは、まず [変数とは何か](/statistics/variable/) に戻り、横軸と縦軸が何を測っているかを確認します。点が細胞、遺伝子、サンプル、個体のどれを表すかは、[n数とは何か](/statistics/sample-size/) と合わせて読むと誤解しにくくなります。

右上がりや右下がりの傾向が見える場合は、[相関と因果の違い](/statistics/correlation-causation/) を確認します。散布図は関係の手がかりを示しますが、それだけで直接の因果関係を示すわけではありません。
