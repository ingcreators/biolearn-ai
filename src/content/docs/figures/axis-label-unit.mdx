Figureを読むときは、値の大小や線の形を見る前に、軸、ラベル、単位、スケール、条件名を確認します。これらは、図が何を測り、何を比較しているかを決める前提です。

最初に「何を、何と比べ、どの単位で測った図か」を言葉にします。ここが曖昧なまま読むと、見た目の差をまったく違う意味に受け取ってしまいます。

## このFigureで何を見るか

このFigureでは、横軸、縦軸、凡例、条件名を対応づけ、値が絶対量なのか相対量なのかを整理します。単位やスケールを先に押さえることで、見た目の差を測定の文脈に戻して読めます。

## 図の構成要素

- 軸ラベル: 横軸と縦軸が示す変数、条件、時間、濃度、測定値を確認します。
- 単位: cells、ng/mL、%、fold change、relative expression など、値の意味を決める情報です。
- スケール: 線形スケール、logスケール、z-score、正規化値では、同じ距離に見えても意味が違います。
- 条件名: control、treated、wild type、mutant、time pointなど、比較の基準を読みます。
- 凡例: 色、線、記号、点の形がどの群や測定対象に対応するかを確認します。

## 読む順番

1. Figure legendと軸ラベルを見て、何を測った図かを確認します。
2. 横軸と縦軸の単位、スケール、基準値を確認します。
3. 条件名と凡例を対応づけ、どれが対照でどれが処理群かを整理します。
4. 値の大小、差の方向、群間の重なりを読みます。
5. エラーバー、n数、統計表示があれば、差の読み方を調整します。

## 前提に戻る

軸に変数名が出てきたら、[変数とは何か](/statistics/variable/)に戻ると、横軸と縦軸を「測定された特徴」として整理できます。エラーバーやp値がある図では、[エラーバーの読み方](/statistics/error-bars/)と[Figure legendの読み方](/figures/figure-legend/)を合わせて確認します。

## よくある誤解

- グラフの高さだけを見て、何を測っているか確認しない。
- relative や normalized の意味を、絶対量と同じように読む。
- logスケールの差を、線形スケールの差と同じ感覚で読む。
- 条件名の順番だけで、どちらが対照かを決めつける。
