## 目的別に選ぶ

| いまの目的                                     | おすすめの入口                                     |
| ---------------------------------------------- | -------------------------------------------------- |
| 生命科学の用語がまだ不安                       | [基礎を固める](/paths/foundations/)                |
| 細胞内で分子がどう働くか知りたい               | [細胞のしくみを理解する](/paths/cell-mechanisms/)  |
| MethodsやFigure legendの確認点を知りたい       | [実験・統計を確認する](/paths/methods-statistics/) |
| RNA-seqやsingle-cell解析を読みたい             | [オミクス解析を読む](/paths/omics-analysis/)       |
| 論文Figureを見ても何から確認するか迷う         | [Figureを読む](/paths/figure-reading/)             |
| 論文全体の読み方や、読む論文の選び方を知りたい | [論文を読む](/paths/paper-reading/)                |

## パスを切り替える目安

| いま使っているパス     | 切り替えるタイミング                                  | 切り替え先                                                                                 |
| ---------------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 基礎を固める           | FigureやMethodsに出てくる用語の前提が分かってきた     | [実験・統計を確認する](/paths/methods-statistics/)、[Figureを読む](/paths/figure-reading/) |
| 細胞のしくみを理解する | 細胞画像やシグナル伝達Figureを読みたい                | [Figureを読む](/paths/figure-reading/)、[実験・統計を確認する](/paths/methods-statistics/) |
| 実験・統計を確認する   | 手法、対照、反復、統計表示の確認点が見えてきた        | [Figureを読む](/paths/figure-reading/)、[論文を読む](/paths/paper-reading/)                |
| オミクス解析を読む     | RNA-seq、single-cell、変異解析の流れが見えてきた      | [Figureを読む](/paths/figure-reading/)、[論文を読む](/paths/paper-reading/)                |
| Figureを読む           | Figure legend、軸、対照、統計表示を拾えるようになった | [論文を読む](/paths/paper-reading/)                                                        |

用語だけ分からない場合は [用語集](/glossary/)、確認点だけ短く見たい場合は [リファレンス](/resources/) に戻ります。
