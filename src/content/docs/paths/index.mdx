ラーニングパスは、分野別の記事を目的に合わせて並べ直した学習ルートです。記事番号ではなく、「何が読めるようになりたいか」から選びます。

コンテンツが増えたため、現在は5つのパスで学習の地図を作っています。基礎で共通語彙を作り、必要に応じて実験・統計やオミクス解析を確認し、Figure読解、論文読解へ進みます。各パスは独立したコースではなく、読んでいる論文やFigureで詰まった場所へ戻るための道筋です。

## 推奨順

初めて学ぶ場合は、[基礎から学ぶ](/paths/foundations/) で用語と全体像を整えます。その後、読めるようになりたい論文に合わせて分岐します。

実験Figureや一般的なResultsを読みたい場合は、[実験・統計を確認する](/paths/methods-statistics/) から [Figureを読めるようになる](/paths/figure-reading/) へ進みます。RNA-seq、single-cell解析、変異解析、ゲノムブラウザ図を読む場合は、[オミクス解析を読む](/paths/omics-analysis/) を挟むと、解析Figureの前提が安定します。

Figureの見方に慣れたら、[論文を読めるようになる](/paths/paper-reading/) で Methods、Results、Discussion を行き来する練習に進みます。特定の記事だけを探したい場合は、ラーニングパスではなく [分野別カテゴリ](/roadmap/) や [用語集](/glossary/) から探します。

## パスとカテゴリの使い分け

ラーニングパスは、目的に合わせて記事を順番に並べ直したものです。カテゴリトップは、特定の分野や記事を探すための入口です。

| ---------------------------------------- | -------------------------------------------------- |
| 順番に練習したい                         | [ラーニングパス](/paths/)                          |
| 生命科学の基礎語彙を固めたい             | [基礎から学ぶ](/paths/foundations/)                |
| Methods、対照、統計表示を確認したい      | [実験・統計を確認する](/paths/methods-statistics/) |
| RNA-seq、single-cell、変異解析を読みたい | [オミクス解析を読む](/paths/omics-analysis/)       |
| Figureの種類から記事を探したい           | [論文Figureの読み方](/figures/)                    |
| 統計・研究デザインだけ確認したい         | [統計・研究デザイン](/statistics/)                 |
| Methodsや実験手法を確認したい            | [実験手法](/methods/)                              |
| 確認点だけ素早く見たい                   | [リファレンス](/resources/)                        |
