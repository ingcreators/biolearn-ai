## パスを選ぶ目安

| いまの目的                                     | おすすめの入口                                         |
| ---------------------------------------------- | ------------------------------------------------------ |
| 後続カテゴリに進む前の共通土台を確認したい     | [基礎を固める](/paths/foundations/)                    |
| 複製、転写、翻訳、発現調節を詳しく知りたい     | [分子のしくみを理解する](/paths/molecular-mechanisms/) |
| 細胞内で分子がどう働くか知りたい               | [細胞のしくみを理解する](/paths/cell-mechanisms/)      |
| MethodsやFigure legendの確認点を知りたい       | [実験・統計を確認する](/paths/methods-statistics/)     |
| RNA-seqやsingle-cell解析を読みたい             | [オミクス解析を読む](/paths/omics-analysis/)           |
| 論文Figureを見ても何から確認するか迷う         | [Figureを読む](/paths/figure-reading/)                 |
| 論文全体の読み方や、読む論文の選び方を知りたい | [論文を読む](/paths/paper-reading/)                    |

## パスを切り替える目安

| いま使っているパス     | 切り替えるタイミング                                  | 切り替え先                                             |
| ---------------------- | ----------------------------------------------------- | ------------------------------------------------------ |
| 基礎を固める           | 遺伝情報が使われ、調節されるしくみを詳しく知りたい    | [分子のしくみを理解する](/paths/molecular-mechanisms/) |
| 分子のしくみを理解する | 分子が細胞内のどこで働き、どう応答するかを知りたい    | [細胞のしくみを理解する](/paths/cell-mechanisms/)      |
| 細胞のしくみを理解する | 実験条件、対照、反復、統計表示の確認点を知りたい      | [実験・統計を確認する](/paths/methods-statistics/)     |
| 実験・統計を確認する   | RNA-seq、single-cell、変異解析の流れを知りたい        | [オミクス解析を読む](/paths/omics-analysis/)           |
| オミクス解析を読む     | RNA-seq、single-cell、変異解析のFigureを読みたい      | [Figureを読む](/paths/figure-reading/)                 |
| Figureを読む           | Figure legend、軸、対照、統計表示を拾えるようになった | [論文を読む](/paths/paper-reading/)                    |

用語だけ分からない場合は [用語集](/glossary/)、分野から探したい場合は [分野別カテゴリ](/categories/)、確認点だけ短く見たい場合は [リファレンス](/resources/) に戻ります。
