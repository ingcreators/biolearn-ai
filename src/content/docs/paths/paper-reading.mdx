このパスでは、論文を最初から順番に訳すのではなく、研究の問い、Figure、Methods、Results、Discussion を行き来しながら読む練習をします。

Figure の見た目だけで結論を決めず、Methods でサンプル、対照、反復、解析条件を確認し、Discussion ではデータから言える範囲と解釈を分けて読みます。

特定の記事や演習を探したい場合は [論文読解演習](/papers/) を使います。このページでは、論文読解の型を順番に身につけることを優先します。

## 目標

- 論文の問い、実験設計、主要結果を分けて読める
- Methods からサンプル、手法、解析条件を確認できる
- Results の主張を Figure と Figure legend に戻って確認できる
- Discussion の解釈と実験結果そのものを分けて読める

## 推奨ルート

1. [論文の構成](/papers/paper-structure/) で、Abstract、Introduction、Methods、Results、Discussion の役割を確認します。
2. [初回読みの流れ](/papers/first-pass-reading/) で、どこから読むかを決めます。
3. [Figureから論文を読む方法](/papers/figure-first-reading/) で、Figure を入口にした読み方を練習します。
4. [Methods確認チェックリスト](/papers/methods-checklist/) で、サンプル、対照、反復、解析条件を確認します。
5. [Resultsの読み方](/papers/how-to-read-results/) と [Discussionの読み方](/papers/how-to-read-discussion/) で、結果と解釈を分けます。
6. [Referencesの読み方](/papers/how-to-read-references/) で、背景、手法、比較対象、次に読む論文として引用文献を使い分けます。
7. [批判的に読む](/papers/critical-reading/) で、限界、代替説明、追加で見たい情報を整理します。

この順番は、論文全体を訳す順番ではありません。まず全体像をつかみ、Figureの主張を確認し、MethodsとResultsへ戻り、最後にDiscussionの解釈を読み分けるための練習順です。

## Figure読解に戻るタイミング

論文読解中にFigureで止まった場合は、論文全体を読み進める前に、Figure読解パスやFigureカテゴリへ戻ります。図の前提、表示方法、統計、Methods確認のどこで止まったかを分けると戻り先を選びやすくなります。

| 止まったところ                        | 戻る場所                                                                                        | 論文読解へ戻る目安                            |
| ------------------------------------- | ----------------------------------------------------------------------------------------------- | --------------------------------------------- |
| Figure legendの条件や略語が読みにくい | [Figure legendの読み方](/figures/figure-legend/)                                                | 条件、n数、反復、統計表示を拾える             |
| 軸、単位、パネル構成が分からない      | [軸・ラベル・単位](/figures/axis-label-unit/)、[複数パネルFigure](/figures/multi-panel-figure/) | 何を比較しているFigureか説明できる            |
| グラフの種類ごとの読み方に迷う        | [論文Figureの読み方](/figures/)                                                                 | Figureの種類から確認点を選べる                |
| 統計表示やn数で止まる                 | [統計・研究デザイン](/statistics/)、[Figure早見表](/resources/figures-cheatsheet/)              | 表示された差の強さと不確かさを分けられる      |
| Figureと本文の主張がつながらない      | [Figureと主張を対応づける](/figures/figure-to-claim/)                                           | Results本文の文とFigureパネルを対応づけられる |

## 用語で迷ったとき

論文読解では、Title、Abstract、Introduction、Methods、Results、Discussion、References、Figure、主張、限界などの言葉が何度も出てきます。順番に練習している途中で特定の部位だけ確認したくなった場合は、[論文読解の用語](/glossary/#paper-section-terms) と [論文読解演習](/papers/) の「論文の部位から探す」から戻ると、対応する記事を選びやすくなります。

Methodsで止まった場合は、[対照群](/glossary/control-group/)、[反復](/glossary/biological-technical-replicates/)、[n数](/glossary/sample-size/)、[Figure legend](/glossary/figure-legend/) を短く確認してから、[Methods確認チェックリスト](/papers/methods-checklist/) に戻ります。
