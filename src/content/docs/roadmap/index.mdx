学習ロードマップは、BioLearn 全体の見取り図です。順番に読むならラーニングパス、分野や記事名から探すなら分野別カテゴリ、途中で確認点だけ見直すならリファレンスを使います。

## BioLearnの構成

| 入口                                   | 使う場面                                   | できること                                     |
| -------------------------------------- | ------------------------------------------ | ---------------------------------------------- |
| [ラーニングパス](/paths/)              | 何から順番に読めばよいか決めたい           | 複数カテゴリの記事を、目的に合わせて順番に読む |
| [分野別カテゴリ](#分野別に探す)        | 分野や記事名から探したい                   | 各分野のトップから、セクション別に記事を探す   |
| [リファレンス](/resources/)            | Figure、Methods、論文探索で迷っている      | 確認点や早見表だけを短く見直す                 |
| [用語集](/glossary/)・[復習](/review/) | 用語だけ確認したい、読んだ記事を見直したい | 用語の意味や学習履歴に戻る                     |

## 使い分け

| 迷い方                                    | 選ぶ入口                        | 判断の目安                                   |
| ----------------------------------------- | ------------------------------- | -------------------------------------------- |
| どの記事から始めるか決めたい              | [ラーニングパス](/paths/)       | 目的に合わせて、読む順番ごと選びます         |
| 分子生物学、統計など分野から探したい      | [分野別カテゴリ](#分野別に探す) | 分野トップから、セクションや記事名で探します |
| 読んでいる論文のMethodsやFigureで止まった | [リファレンス](/resources/)     | 早見表で確認点を短く見直します               |
| 用語の意味だけ確認したい                  | [用語集](/glossary/)            | 記事に戻る前に、語の意味を確認します         |
| 読んだ記事を復習したい                    | [学習履歴と復習](/review/)      | 学習状況や確認問題を見直します               |

## ラーニングパスで読む

順番に読む場合は、まずラーニングパスを選びます。パスは分野をまたいで、論文読解につながる順番に記事を並べています。

| 目的                                         | 入口                                               |
| -------------------------------------------- | -------------------------------------------------- |
| 生命科学の共通語彙を作りたい                 | [基礎を固める](/paths/foundations/)                |
| 細胞内で分子がどう働くか理解したい           | [細胞のしくみを理解する](/paths/cell-mechanisms/)  |
| Methodsや統計表示の確認点を押さえたい        | [実験・統計を確認する](/paths/methods-statistics/) |
| RNA-seq、single-cell解析、変異解析を読みたい | [オミクス解析を読む](/paths/omics-analysis/)       |
| 論文Figureを読む練習をしたい                 | [Figureを読む](/paths/figure-reading/)             |
| 論文全体の読み方を練習したい                 | [論文を読む](/paths/paper-reading/)                |

どのパスから始めるか迷う場合は、[ラーニングパス](/paths/) で目的別の入口を確認します。

## 分野別に探す

読みたい分野や記事名が分かっている場合は、分野別カテゴリを使います。カテゴリトップでは、セクションごとに記事を探せます。

| 探したいこと                      | 入口                                         |
| --------------------------------- | -------------------------------------------- |
| 生命科学の基本語                  | [生命科学の基礎](/fundamentals/)             |
| DNA、RNA、タンパク質、遺伝子発現  | [分子生物学](/molecular-biology/)            |
| 細胞膜、小器官、シグナル伝達      | [細胞生物学](/cell-biology/)                 |
| ゲノム、染色体、変異              | [ゲノミクス](/genomics/)                     |
| PCR、qPCR、NGS、Western blotなど  | [実験手法](/methods/)                        |
| RNA-seq、発現解析、オミクスデータ | [バイオインフォマティクス](/bioinformatics/) |
| n数、p値、反復、研究デザイン      | [統計・研究デザイン](/statistics/)           |
| Figureの種類ごとの読み方          | [論文Figureの読み方](/figures/)              |
| 論文全体の読み方                  | [論文読解演習](/papers/)                     |

## 迷ったとき

| 状況                                  | 進む場所                    |
| ------------------------------------- | --------------------------- |
| 何から読めばよいか分からない          | [ラーニングパス](/paths/)   |
| 記事名や分野が分かっている            | このページの分野別カテゴリ  |
| 用語だけ短く確認したい                | [用語集](/glossary/)        |
| FigureやMethodsの確認点だけ見直したい | [リファレンス](/resources/) |
| 読んだ記事を復習したい                | [学習履歴と復習](/review/)  |
