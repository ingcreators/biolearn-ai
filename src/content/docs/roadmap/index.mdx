## ラーニングパスで読む

| 目的                                         | 入口                                               |
| -------------------------------------------- | -------------------------------------------------- |
| 生命科学の共通語彙を作りたい                 | [基礎を固める](/paths/foundations/)                |
| 細胞内で分子がどう働くか理解したい           | [細胞のしくみを理解する](/paths/cell-mechanisms/)  |
| Methodsや統計表示の確認点を押さえたい        | [実験・統計を確認する](/paths/methods-statistics/) |
| RNA-seq、single-cell解析、変異解析を読みたい | [オミクス解析を読む](/paths/omics-analysis/)       |
| 論文Figureを読む練習をしたい                 | [Figureを読む](/paths/figure-reading/)             |
| 論文全体の読み方を練習したい                 | [論文を読む](/paths/paper-reading/)                |

どのパスから始めるか迷う場合は、[ラーニングパス](/paths/) で目的別の入口を確認します。

| 探したいこと                      | 入口                                         |
| --------------------------------- | -------------------------------------------- |
| 生命科学の基本語                  | [生命科学の基礎](/fundamentals/)             |

| 細胞膜、小器官、シグナル伝達      | [細胞生物学](/cell-biology/)                 |

| PCR、qPCR、NGS、Western blotなど  | [実験手法](/methods/)                        |
| RNA-seq、発現解析、オミクスデータ | [バイオインフォマティクス](/bioinformatics/) |
| n数、p値、反復、研究デザイン      | [統計・研究デザイン](/statistics/)           |

| 論文全体の読み方                  | [論文読解演習](/papers/)                     |
