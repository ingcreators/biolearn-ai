## 到達目標

このロードマップを一通りたどると、次の状態を目指せます。

- DNA、RNA、タンパク質、遺伝子、ゲノムの違いを説明できる
- 分子、細胞、ゲノム、実験データを別々の暗記項目ではなく、つながったものとして捉えられる
- PCR、qPCR、NGS、Western blot、免疫染色、フローサイトメトリーが何を測っているか確認できる
- RNA-seq、差次的発現解析、single-cell解析の結果を Figure として読む準備ができる
- n数、反復、p値、効果量、バイアス、交絡を見て、主張の強さを慎重に判断できる
- Figure legend、軸、条件、コントロール、Methodsを確認しながら、論文 Figure を読める
- Abstract、Results、Methods、Discussion を行き来して、論文の主張をデータに戻せる

### この領域を終えるとできること

- 分子、細胞、組織、個体の階層を区別できる
- DNA、RNA、タンパク質、遺伝子、ゲノム、染色体を区別できる
- 遺伝子発現、変異、表現型、モデル生物、生命科学の問いを、Figureや論文を読む入口として説明できる

- 分子生物学、細胞生物学、ゲノミクス、バイオインフォマティクスがつながった学習領域だと理解できる

## 分子生物学

### この領域で学ぶこと

DNA、RNA、タンパク質を、情報の保存、読み出し、働きの流れとして学びます。セントラルドグマ、転写、翻訳、遺伝子発現を整理し、RNA-seq や発現解析へ進む土台を作ります。

### 読む記事一覧

1. [セントラルドグマとは何か](/molecular-biology/central-dogma/)
2. [転写とは何か](/molecular-biology/transcription/)
3. [翻訳とは何か](/molecular-biology/translation/)
4. [遺伝子発現とは何か](/fundamentals/gene-expression/)

### この領域を終えるとできること

- 転写と翻訳が、遺伝情報からタンパク質へ向かう流れのどこにあるか説明できる
- 遺伝子発現を、細胞の状態や実験データと結びつけて考えられる
- RNA-seq の「発現量」が何を手がかりにした言葉なのか見通せる

## 細胞生物学

### この領域で学ぶこと

分子の働きが、細胞という場所でどう機能として現れるのかを学びます。細胞膜、細胞小器官、細胞シグナル伝達を通して、外からの刺激、受容体、タンパク質、遺伝子発現のつながりを整理します。

### 読む記事一覧

1. [細胞膜とは何か](/cell-biology/cell-membrane/)
2. [細胞小器官とは何か](/cell-biology/organelles/)
3. [細胞シグナル伝達とは何か](/cell-biology/cell-signaling/)

### この領域を終えるとできること

- 細胞膜が、細胞の内外を分けるだけでなく情報の入口にもなることを説明できる
- 細胞小器官を、分子が働く場所として捉えられる
- シグナル伝達と遺伝子発現の変化をつなげて考えられる

## ゲノミクス

### この領域で学ぶこと

遺伝情報を、単一の遺伝子だけでなくゲノム全体として捉えます。ゲノム、染色体、遺伝的変異、ゲノムブラウザを通して、配列情報を広い文脈で読みます。

### 読む記事一覧

1. [ゲノムとは何か](/fundamentals/genome/)
2. [染色体とは何か](/fundamentals/chromosome/)
3. [変異とは何か](/fundamentals/mutation/)
4. [遺伝的変異とは何か](/genomics/genetic-variants/)
5. [ゲノムブラウザとは何か](/genomics/genome-browser/)

### この領域を終えるとできること

- 遺伝子、ゲノム、染色体を混同せずに説明できる
- 遺伝的変異を、ゲノム配列の違いとして捉えられる
- ゲノムブラウザ図や変異図を読むための位置づけを持てる

## 目的別ルート

目的がはっきりしている場合は、次の入口から始めても構いません。

### 高校生物を学び直したい

[生命科学とは何か](/fundamentals/life-science/) から順番に読みます。各記事の確認問題で説明できない用語があれば、[用語集](/glossary/) に戻ります。

### 分子生物学を先に学びたい

[DNAとは何か](/fundamentals/dna/) から [遺伝子発現とは何か](/fundamentals/gene-expression/) までを読みます。その後、細胞生物学へ進むと、分子がどこで働くかを理解しやすくなります。

### バイオインフォマティクスに進みたい

いきなりRNA-seqへ進まず、[遺伝子発現とは何か](/fundamentals/gene-expression/) と [バイオインフォマティクスとは何か](/bioinformatics/bioinformatics/) を読んでから [RNA-seqとは何か](/bioinformatics/rna-seq/) に進みます。差次的発現解析へ進む前に、[ゲノムとは何か](/fundamentals/genome/) も読んでおくと位置づけが安定します。

### 論文Figureを読みたい

まず [Figureを読めるようになる](/paths/figure-reading/) を使います。分野別に探す場合は、[実験手法](/methods/)、[バイオインフォマティクス](/bioinformatics/)、[統計・研究デザイン](/statistics/)、[論文Figureの読み方](/figures/) を行き来します。

### 論文全体を読めるようになりたい

先に Figure と Methods に戻る感覚を作り、その後 [論文を読めるようになる](/paths/paper-reading/) へ進みます。読む論文を探すところから始めたい場合は、[読む論文の選び方](/papers/how-to-choose-paper/) と [PubMedとは何か](/papers/pubmed/) を使います。

## 学習チェック

次の問いに自分の言葉で答えられれば、ロードマップの土台はできています。

- DNA、遺伝子、ゲノム、染色体の違いは何ですか。
- 転写と翻訳はどちらが先に起こりますか。
- 遺伝子発現は細胞の状態とどう関係しますか。
- PCR、qPCR、NGS、Western blot は、それぞれ何を測る手法ですか。
- RNA-seqでは何を測っていると言えますか。
- 差次的発現解析の結果を見るとき、p値以外に何を確認しますか。
- 論文Figureを読むとき、軸、条件、コントロール、ばらつきのうち何を最初に確認しますか。
- 論文のDiscussionで述べられた解釈を、どのFigureやMethodsに戻って確認しますか。
