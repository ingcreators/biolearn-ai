分布は、データがどの値にどれくらい集まっているかを示す見方です。

<LessonFigure
  src="/figures/distribution-concept.jpg"
  alt="同じ平均でも狭い分布と広い分布があり、データの散らばり方が異なることを示す概念図"
  title="分布は値の集まり方を示す"
  caption="平均だけでなく、広がり、偏り、外れ値を確認します。"
/>

同じ平均値を持つデータでも、値の散らばり方は大きく異なることがあります。あるデータは平均の近くに集まり、別のデータは広く散らばるかもしれません。片側に長く伸びる分布や、2つの山を持つ分布もあります。

生命科学のFigureでは、点、箱ひげ図、バイオリンプロット、ヒストグラムなどで分布が示されます。平均やp値を見る前に、データがどのように広がっているかを見ると、結果を読みすぎにくくなります。

## なぜ重要か

分布を見ると、外れ値、ばらつき、群内の多様性、少数のサブグループに気づきやすくなります。特に細胞ごとの値やサンプル数が限られた実験では、平均だけでなく分布を見ることが大切です。

## Figureで見る場所

分布は、[箱ひげ図の読み方](/figures/how-to-read-box-plot/)や[バイオリンプロットの読み方](/figures/how-to-read-violin-plot/)で直接読みます。平均やp値を見る前に、点の広がり、外れ値、山の数、群内のばらつきを確認すると、Figureの結論を読みすぎにくくなります。

## 英語表記と略語

| 日本語名 | 英語名       | 略語 |
| -------- | ------------ | ---- |
| 分布     | distribution | -    |
| 外れ値   | outlier      | -    |
| ばらつき | variability  | -    |
| 偏り     | skewness     | -    |

## よくある誤解

- 平均が同じなら分布も同じだと思ってしまう。
- 点の重なりや外れ値を見ずに、棒の高さだけを見る。
- 分布の形から原因まで一気に断定する。

## 重要用語

- 分布: 値の集まり方。
- 外れ値: 他の値から大きく離れた値。
- ばらつき: データがどれくらい散らばっているか。
- ヒストグラム: 値の範囲ごとの数を示す図。
