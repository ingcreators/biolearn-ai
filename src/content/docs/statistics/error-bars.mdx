エラーバーは、データのばらつきや平均値の不確かさを示す図上の表示です。

棒グラフや折れ線グラフには、上下に線が伸びたエラーバーが付くことがあります。ただし、同じ見た目でも意味は論文によって異なります。

よく使われる表示には、標準偏差（SD）、標準誤差（SEM）、信頼区間（CI）があります。SDはデータそのもののばらつき、SEMは平均値の推定の不確かさ、信頼区間は推定値の範囲を考えるための表示です。

Figureを読むときは、エラーバーが何を表しているかをFigure legendで確認します。エラーバーの重なりだけで有意差の有無を判断するのではなく、統計検定や実験設計も合わせて見ます。

## なぜ重要か

エラーバーは、平均値だけでは見えないばらつきや不確かさを伝えます。Figureの差が大きく見えても、ばらつきが大きい場合や反復が少ない場合には、解釈に注意が必要です。

## Figureで見る場所

エラーバーは、[棒グラフの読み方](/figures/how-to-read-bar-plot/)や[Forest plotの読み方](/figures/how-to-read-forest-plot/)で特に重要です。棒グラフでは平均の周りのばらつきや不確かさ、Forest plotでは推定値の信頼区間として読むことがあります。

## 英語表記と略語

| 日本語名   | 英語名                     | 略語 |
| ---------- | -------------------------- | ---- |
| エラーバー | error bar                  | -    |
| 標準偏差   | standard deviation         | SD   |
| 標準誤差   | standard error of the mean | SEM  |
| 信頼区間   | confidence interval        | CI   |

## よくある誤解

- エラーバーは常に標準偏差とは限りません。
- エラーバーが重なっているかどうかだけで、統計的有意性を判断することはできません。
- エラーバーが小さいからといって、実験設計が十分とは限りません。

## 重要用語

- SD: データのばらつきを表す指標。
- SEM: 平均値の推定の不確かさを表す指標。
- CI: 推定値が入りそうな範囲を考えるための表示。
- Figure legend: エラーバーの定義が書かれることが多い説明文。
