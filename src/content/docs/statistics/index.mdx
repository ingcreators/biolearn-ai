統計・研究デザインでは、Figure や Results に出てくる差、ばらつき、サンプル数、統計的な確からしさを読むための考え方を学びます。

## この分野で学ぶこと

- 変数、分布、平均、中央値の基本
- 反復、n数、対照群、ランダム化、盲検化の見方
- ばらつき、エラーバー、信頼区間の基本
- p値、効果量、多重検定の考え方
- Figureの軸、代表値、分布、推定の不確かさを分けて読むこと
- 相関と因果、有意性と重要性、バイアスを区別してDiscussionを読むこと

## おすすめの読み順

初めて読む場合は、まずデータが何を表しているかを押さえ、次に比較の設計を確認し、その後でエラーバーやp値へ進むと読みやすくなります。

1. [変数とは何か](/statistics/variable/) → [分布とは何か](/statistics/distribution/) → [平均と中央値](/statistics/mean-median/)
2. [生物学的反復と技術的反復](/statistics/biological-technical-replicates/) → [n数とは何か](/statistics/sample-size/) → [対照群とは何か](/statistics/control-group/) → [ランダム化とは何か](/statistics/randomization/) → [盲検化とは何か](/statistics/blinding/)
3. [エラーバーとは何か](/statistics/error-bars/) → [標準偏差と標準誤差とは何か](/statistics/standard-deviation-standard-error/) → [信頼区間とは何か](/statistics/confidence-interval/)
4. [p値とは何か](/statistics/p-value/) → [効果量とは何か](/statistics/effect-size/) → [多重検定補正とは何か](/statistics/multiple-testing-correction/) → [統計的有意性と生物学的重要性](/statistics/significance-vs-importance/)
5. [相関と因果の違い](/statistics/correlation-causation/) → [交絡とは何か](/statistics/confounding/) → [バイアスとは何か](/statistics/bias/) → [再現性とは何か](/statistics/reproducibility/) → [研究の限界の読み方](/statistics/limitations/)
