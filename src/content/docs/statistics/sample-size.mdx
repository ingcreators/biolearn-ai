## 要点

n数は、Figureや統計解析で数えられている単位です。

## 基礎解説

論文のFigureでは、`n = 3`、`n = 6 mice`、`n = 120 cells` のような表記がよく出てきます。大切なのは、nの数字だけでなく、何を数えたnなのかを確認することです。

同じ `n = 100` でも、独立した100個体なのか、1つのサンプル内の100細胞なのかで意味は大きく変わります。細胞数が多いことは情報量を増やしますが、独立した生物学的反復が多いことと同じではありません。

## なぜ重要か

n数を読み違えると、Figureの確からしさを過大に見積もることがあります。p値、エラーバー、信頼区間を読む前に、どの単位が独立しているのかをMethodsやFigure legendで確認します。

## 英語表記と略語

| 日本語名 | 英語名           | 略語 |
| -------- | ---------------- | ---- |
| n数      | sample size      | n    |
| サンプル | sample           | -    |
| 独立単位 | independent unit | -    |
| 細胞数   | number of cells  | -    |

## よくある誤解

- nが大きければ、必ず独立サンプルが多いと思ってしまう。
- `n = cells` と `n = animals` を同じ重みで読む。
- Figure legendにn数が書かれていても、Methodsで独立単位を確認しない。

## 重要用語

- n数: 解析や表示で数えられている単位の数。
- 独立単位: 統計的な比較で独立とみなす単位。
- 生物学的反復: 独立した生物学的サンプルの繰り返し。
- 技術的反復: 同じサンプルを測定上繰り返すこと。
