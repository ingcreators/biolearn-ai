## 要点

信頼区間は、平均や差などの推定値について、不確かさを範囲として示す考え方です。

## 基礎解説

実験では、手元のサンプルから平均値や群間差を推定します。しかし、サンプルを取り直せば推定値は少し変わる可能性があります。信頼区間は、その推定の不確かさを範囲として示します。

Figureでは、95%信頼区間のように書かれることがあります。これは「この1つの区間に真の値が95%の確率で入る」と単純に読むものではありませんが、推定値の幅や精度を考えるための重要な手がかりになります。

## なぜ重要か

p値だけを見ると、差がどれくらいの範囲であり得るのかが見えにくくなります。信頼区間を見ると、推定値がどの程度不確かか、差の大きさがどの範囲にありそうかを考えやすくなります。

## Figureで見る場所

信頼区間は、[Forest plotの読み方](/figures/how-to-read-forest-plot/)で横線として出ることがあります。また、棒グラフや点推定の図では、エラーバーが信頼区間を表している場合があります。Figure legendで何を示す線かを確認します。

## 英語表記と略語

| 日本語名 | 英語名              | 略語 |
| -------- | ------------------- | ---- |
| 信頼区間 | confidence interval | CI   |
| 推定値   | estimate            | -    |
| 点推定   | point estimate      | -    |
| 不確かさ | uncertainty         | -    |

## よくある誤解

- 信頼区間を、個々のデータが入る範囲と読む。
- 信頼区間が狭いだけで、結果が生物学的に重要だと判断する。
- エラーバーが必ず信頼区間だと思い込む。

## 重要用語

- 信頼区間: 推定値の不確かさを示す範囲。
- 推定値: データから推定した平均や差などの値。
- 点推定: 1つの値として示した推定。
- エラーバー: 図上で不確かさやばらつきを示す線。
