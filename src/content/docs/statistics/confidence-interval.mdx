信頼区間は、平均や差などの推定値について、不確かさを範囲として示す考え方です。

<LessonFigure
  src="/figures/confidence-interval-concept.jpg"
  alt="推定値の点の周囲に信頼区間の線が伸び、不確かさの範囲を示す概念図"
  title="信頼区間は推定値の不確かさを範囲で示す"
  caption="点推定だけでなく、範囲の幅と比較の基準を確認します。"
/>

実験では、手元のサンプルから平均値や群間差を推定します。しかし、サンプルを取り直せば推定値は少し変わる可能性があります。信頼区間は、その推定の不確かさを範囲として示します。

Figureでは、95%信頼区間のように書かれることがあります。これは「この1つの区間に真の値が95%の確率で入る」と単純に読むものではありませんが、推定値の幅や精度を考えるための重要な手がかりになります。

## なぜ重要か

p値だけを見ると、差がどれくらいの範囲であり得るのかが見えにくくなります。信頼区間を見ると、推定値がどの程度不確かか、差の大きさがどの範囲にありそうかを考えやすくなります。

## 具体例

平均差の95%信頼区間が「2から8」であれば、推定された差は5で、その不確実性の範囲が2から8程度であると読みます。効果量の信頼区間が広い場合、推定の精度が低いことを示します。

サンプル数が増えたり、ばらつきが小さくなったりすると、信頼区間は狭くなる傾向があります。

## よく混同される概念

- 信頼区間とデータの範囲: 信頼区間は推定値の不確実性で、観測値の最小最大ではありません。
- 信頼区間とp値: どちらも不確実性に関係しますが、示している情報は同じではありません。
- 95%信頼区間と「真の値が95%の確率で入る」: 厳密には、同じ手順を繰り返したときの区間の性質を表します。

## 論文や実験ではどう出てくるか

論文では、平均値、効果量、リスク比、オッズ比、回帰係数などに信頼区間が添えられます。Figureでは、点推定と横線や縦線として示されることがあります。

読むときは、区間の幅、ゼロや1などの基準値をまたぐか、効果の大きさとして意味がある範囲かを確認します。

## Figureで見る場所

信頼区間は、[Forest plotの読み方](/figures/how-to-read-forest-plot/)で横線として出ることがあります。また、棒グラフや点推定の図では、エラーバーが信頼区間を表している場合があります。Figure legendで何を示す線かを確認します。

## 英語表記と略語

| 日本語名 | 英語名              | 略語 |
| -------- | ------------------- | ---- |
| 信頼区間 | confidence interval | CI   |
| 推定値   | estimate            | -    |
| 点推定   | point estimate      | -    |
| 不確かさ | uncertainty         | -    |

## よくある誤解

- 信頼区間を、個々のデータが入る範囲と読む。
- 信頼区間が狭いだけで、結果が生物学的に重要だと判断する。
- エラーバーが必ず信頼区間だと思い込む。

## 重要用語

- 信頼区間: 推定値の不確かさを示す範囲。
- 推定値: データから推定した平均や差などの値。
- 点推定: 1つの値として示した推定。
- エラーバー: 図上で不確かさやばらつきを示す線。
