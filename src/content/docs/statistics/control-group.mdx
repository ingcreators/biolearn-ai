対照群は、処理群や観察対象を解釈するための比較の基準です。

<LessonFigure
  src="/figures/control-group-concept.jpg"

  title="対照群は比較の基準を作る"
  caption="目的の処理以外の条件が揃っているかをMethodsで確認します。"
/>

研究で「処理によって変化した」と言うには、何と比べて変化したのかが必要です。その基準になる群が対照群です。

統計・研究デザインの観点では、対照群と処理群で、目的の条件以外ができるだけ揃っているかを見ます。培養条件、測定日、サンプルの由来、処理時間、データ処理の方法などが大きく違うと、観察された差が目的の処理によるものか判断しにくくなります。

## なぜ重要か

Figureで棒や点が並んでいるとき、どの群を基準にして差を見ているのかを確認する必要があります。対照群が不適切だと、p値や効果量が示されていても、比較そのものの意味が弱くなります。

## 英語表記と略語

| 日本語名 | 英語名           | 略語 |
| -------- | ---------------- | ---- |
| 対照群   | control group    | -    |
| 処理群   | treatment group  | -    |
| 比較群   | comparison group | -    |
| 交絡     | confounding      | -    |

## よくある誤解

- 対照群があるだけで、比較が十分に公平だと思ってしまう。
- 「untreated」と「vehicle control」の違いを確認しない。
- 複数の比較があるFigureで、どの対照群との比較かを見落とす。

## 重要用語

- 対照群: 比較の基準になる群。
- 処理群: 目的の処理や条件を受けた群。
- 交絡: 目的の要因以外の違いが結果に影響すること。
- 比較設計: どの群どうしを比べるかの設計。
