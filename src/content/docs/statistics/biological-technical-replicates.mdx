生物学的反復は独立したサンプルや実験単位の繰り返しで、技術的反復は同じサンプルを測定上繰り返すことです。

生命科学論文では `n = 3` や `n = 100 cells` のような表記がよく出てきます。ただし、nが何を数えているかは必ず確認する必要があります。

生物学的反復は、別々の個体、別々に培養した細胞、独立して調製したサンプルなど、実験対象のばらつきを含む繰り返しです。一方、技術的反復は、同じサンプルを複数回測ることで測定のばらつきを確認する繰り返しです。

たとえば同じ培養皿から100個の細胞を測った場合、細胞数としては大きく見えても、独立した生物学的反復が100あるとは限りません。Figure legendやMethodsで、何が独立した単位なのかを確認します。

## なぜ重要か

反復の種類を区別できると、Figureの信頼性を読みやすくなります。p値やエラーバーを見る前に、そもそも比較がどの独立単位に基づいているのかを考えることが大切です。

## 具体例

3匹のマウスからそれぞれ細胞を取り、同じ測定を行う場合は生物学的反復になります。一つのサンプルを同じqPCRプレートで3ウェル測る場合は技術的反復です。

同じ培養皿から分けた測定を何度繰り返しても、独立した生物学的反復とは言いにくい場合があります。

## よく混同される概念

- 生物学的反復と技術的反復: 前者は独立した生物学的サンプル、後者は測定手順の繰り返しです。
- n数と測定回数: 技術的反復を増やしても、生物学的な独立サンプル数が増えるわけではありません。
- 再現性と反復数: 反復は再現性を支える要素ですが、設計や測定の妥当性も必要です。

## 論文や実験ではどう出てくるか

Figure legendでは「n = 3 biological replicates」「technical triplicates」などと書かれます。Methodsでは、独立実験の回数、サンプル数、測定の繰り返し方が説明されます。

読むときは、グラフ上の点が何を表すのか、統計検定でどちらの反復をnとして扱っているのかを確認します。

## 英語表記と略語

| 日本語名     | 英語名                 | 略語 |
| ------------ | ---------------------- | ---- |
| 生物学的反復 | biological replicate   | -    |
| 技術的反復   | technical replicate    | -    |
| 独立実験     | independent experiment | -    |
| サンプル数   | sample size            | n    |

## よくある誤解

- 細胞をたくさん数えたことと、独立サンプルが多いことは同じではありません。
- 技術的反復は測定の安定性を見る助けになりますが、生物学的なばらつきを十分に表すとは限りません。
- n数は大きさだけでなく、何を数えたnなのかが重要です。

## 重要用語

- 生物学的反復: 独立したサンプルや実験単位の繰り返し。
- 技術的反復: 同じサンプルを測定上繰り返すこと。
- 独立実験: 別の日や別の調製として独立に行われた実験。
- n数: 解析や表示に使われた数。何を数えたかの確認が必要。
