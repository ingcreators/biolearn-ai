バイオインフォマティクスは、DNA配列、RNA発現、タンパク質などの生命科学データを計算機で扱う分野です。BioLearnでは、測定結果がデータになり、前処理、解析、Figureでの表示、解釈へ進む流れを学びます。

DNA、RNA、遺伝子発現、ゲノムの考え方があいまいな場合は、先に [生命科学の基礎](/fundamentals/) と [ゲノミクス](/genomics/) を確認すると読みやすくなります。
