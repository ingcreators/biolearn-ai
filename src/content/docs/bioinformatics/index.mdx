バイオインフォマティクスは、DNA配列、RNA発現、タンパク質、臨床研究に関連するデータなどを計算機で扱う分野です。

MVPでは [RNA-seqとは何か](/bioinformatics/what-is-rna-seq/) から、遺伝子発現データ解析の入口を学びます。

RNA-seqに進む前に、[DNAとは何か](/molecular-biology/what-is-dna/)、[RNAとは何か](/molecular-biology/what-is-rna/)、[ゲノムとは何か](/genomics/what-is-genome/) を読んでおくと理解しやすくなります。データ解析へ進む場合は、[シーケンスデータとは何か](/bioinformatics/what-is-sequence-data/) と [差次的発現解析とは何か](/bioinformatics/what-is-differential-expression-analysis/) を続けて読むのがおすすめです。
