## まず一言でいうと

差次的発現解析は、条件の違いによって遺伝子発現が変わっているかを調べる解析です。

## 本文

RNA-seqでは、各遺伝子に対応するリード数を数え、発現量の指標を作ります。ただし、試料ごとの総リード数や技術的な違いがあるため、比較の前に正規化が必要です。

差次的発現解析では、条件Aと条件Bで発現量が異なる遺伝子を統計的に調べます。たとえば、処理前と処理後、細胞種Aと細胞種B、刺激ありと刺激なしのような比較を行います。解析の目的は、条件によって発現が変化している可能性のある遺伝子を見つけることです。

結果には、発現変化の大きさを表す指標と、統計的な確からしさを表す指標が含まれます。log fold changeは変化の方向と大きさを示し、p値や調整済みp値は偶然では説明しにくい差かどうかを考える手がかりになります。ただし、数値だけで意味を決めるのではなく、実験の目的に照らして解釈します。

結果を見るときは、p値や調整済みp値だけでなく、発現変化の大きさ、実験設計、再現性、生物学的な意味も合わせて考えます。差次的発現解析は、候補を見つける強力な方法ですが、最終的な解釈には追加の検証や文献知識が必要になることがあります。

<TermBox term="差次的発現解析" english="differential expression analysis" abbreviation="DEA">
条件間で遺伝子発現に差があるかを統計的に調べる解析です。
</TermBox>

## 名称の対応表

| 日本語名 | 英語名 | 略語 |
| --- | --- | --- |
| 差次的発現解析 | differential expression analysis | DEA |
| 正規化 | normalization | - |
| 調整済みp値 | adjusted p-value | FDR |
| 対数変化倍率 | log fold change | logFC |

## よくある誤解

- p値が小さいだけで、生物学的に重要とは限りません。
- 解析結果は実験設計やサンプル数に大きく影響されます。

## 重要用語

- 差次的発現解析 / differential expression analysis
- 正規化 / normalization
- 調整済みp値 / adjusted p-value
- 対数変化倍率 / log fold change
