RNAは、DNAの情報を使う場面で働く、柔軟な役割を持つ分子です。

RNAはリボ核酸の略です。DNAと似ていますが、一般に一本鎖で働くことが多く、塩基としてTの代わりにUを使います。タンパク質の材料情報を運ぶmRNA、リボソームの構成要素であるrRNA、アミノ酸を運ぶtRNAなど、複数の種類があります。

RNAは、DNAに保存された情報を細胞内で使うための重要な分子です。mRNAはタンパク質合成に使われる情報を運びますが、RNAの役割はそれだけではありません。rRNAはリボソームの一部として働き、tRNAは翻訳のときにアミノ酸を運びます。

DNAからRNAが作られる過程を転写と呼びます。転写されたRNAは、そのまま使われる場合もあれば、加工を受けてから働く場合もあります。真核生物では、mRNAが成熟するまでに不要な部分が取り除かれたり、末端に構造が加えられたりします。

RNAは単なる中継役に限らず、遺伝子発現の調節にも関わります。RNAの量や種類を調べることで、細胞がどの遺伝子をどれくらい使っているかを推定できます。この考え方は、後で学ぶRNA-seqにつながります。

## なぜ重要か

[RNA](/glossary/rna/)は、[DNA](/glossary/dna/)に保存された情報が細胞内で使われるときの中心的な分子です。[転写](/glossary/transcription/)によってRNAが作られ、その量や種類は細胞の状態を反映します。

RNAを理解すると、[遺伝子発現](/glossary/gene-expression/)や[RNA-seq](/glossary/rna-seq/)の考え方が分かりやすくなります。多くの実験では、細胞がどの遺伝子を使っているかをRNA量から推定します。

## 具体例

mRNAは、タンパク質を作るための情報をリボソームへ伝えます。rRNAはリボソームの主要な構成要素として働き、tRNAはアミノ酸を運んでコドンと対応づけます。

細胞に刺激を与えると、ある遺伝子のmRNA量が増えることがあります。このとき研究者は、qPCRやRNA-seqでmRNA量を測り、その細胞がどのような応答をしているかを推定します。

## よく混同される概念

- RNAとmRNA: mRNAはRNAの一種です。RNAにはrRNA、tRNA、調節性RNAなどもあります。
- 転写と翻訳: 転写はDNAからRNAを作る過程で、翻訳はmRNAの情報からタンパク質を作る過程です。
- RNA量とタンパク質量: mRNAが多いからといって、必ずタンパク質も同じ割合で多いとは限りません。

## 論文や実験ではどう出てくるか

RNAは、RT-qPCR、RNA-seq、ノーザンブロット、in situ hybridizationなどで登場します。論文では「この遺伝子のmRNA発現が上昇した」「RNA-seqで発現変動遺伝子を同定した」のように、細胞状態を読むための指標として使われることが多いです。

## 英語表記と略語

| 日本語名          | 英語名           | 略語 |
| ----------------- | ---------------- | ---- |
| リボ核酸          | ribonucleic acid | RNA  |
| メッセンジャーRNA | messenger RNA    | mRNA |
| リボソームRNA     | ribosomal RNA    | rRNA |
| 転移RNA           | transfer RNA     | tRNA |
| 転写              | transcription    | -    |

## よくある誤解

- RNAはmRNAだけではありません。rRNA、tRNA、調節性RNAなど多様な種類があります。
- RNAはDNAの劣化版ではなく、独自の機能を持ちます。

## 重要用語

- RNA: DNAの情報を読み出し、タンパク質合成や調節に関わる分子。
- mRNA: タンパク質を作るための情報を運ぶRNA。
- rRNA: リボソームの主要な構成要素となるRNA。
- tRNA: アミノ酸をリボソームへ運び、コドンに対応づけるRNA。
- 転写: [転写](/glossary/transcription/)はDNAの情報をもとにRNAを合成する過程。
