変異は、DNA配列に生じた変化を指す言葉です。

DNAは、A、T、G、Cという塩基の並びとして情報を持っています。この並びの一部が置き換わったり、追加されたり、失われたりした状態を変異と呼びます。変異は細胞分裂の過程、DNA修復の失敗、外的要因などによって生じることがあります。

変異にはいくつかの種類があります。1つの塩基が別の塩基に置き換わる変化、短い配列が挿入される変化、配列の一部が欠失する変化などです。より大きな範囲では、コピー数の変化や染色体構造の変化として扱われることもあります。

学習では、変異、遺伝的変異、SNPを分けると理解しやすくなります。変異はDNA配列の変化を広く指す言葉です。遺伝的変異は、個体や細胞の間で見られるゲノム配列の違いを広く扱う表現です。SNPは、その中でも集団内で比較的よく見られる1塩基の違いを指します。

変異があるからといって、必ず大きな影響があるわけではありません。遺伝子のどこにあるか、タンパク質の配列を変えるか、調節領域にあるか、集団の中でどれくらい見られるかによって、解釈は変わります。この教材では、個人の診断や治療判断ではなく、論文やFigureを読むための基礎概念として扱います。

## なぜ重要か

[変異](/glossary/mutation/)は、[ゲノム](/glossary/genome/)を「固定された一つの配列」ではなく、違いを含む情報として読むための入口です。ゲノム解析、疾患研究、進化、細胞の性質の変化を理解するときに、変異という考え方が土台になります。

一方で、変異を見つけることと、意味を確定することは別です。論文では、変異の種類、位置、頻度、機能実験、統計的な関連を合わせて、どこまで言えるかを慎重に読ませる必要があります。

## 具体例

あるDNA配列の一部で、もとの塩基AがGに置き換わることがあります。これが1塩基の置換です。集団内でよく見られる1塩基の違いとして扱う場合は、SNPと呼ばれることがあります。

別の例では、数塩基が挿入されたり、欠失したりします。タンパク質を作る領域で起こると、アミノ酸配列や読み枠に影響する場合があります。ただし、影響の大きさは場所や種類によって異なります。

## よく混同される概念

- 変異とSNP: SNPは変異の一種ですが、すべての変異がSNPではありません。
- 変異と病的変化: 変異は配列の変化を指す言葉で、必ず悪い意味を持つわけではありません。
- 変異の検出と解釈: シーケンスデータから変異候補を見つけても、その生物学的な意味は別に検討します。

## 論文や実験ではどう出てくるか

変異は、全ゲノムシーケンシング、エクソーム解析、がんゲノム解析、GWAS、CRISPR実験などで登場します。Figureでは、変異の位置を示す図、ロリポッププロット、ゲノムブラウザ、変異リスト、アリル頻度の図として示されることがあります。

## 英語表記と略語

| 日本語名   | 英語名                         | 略語    |
| ---------- | ------------------------------ | ------- |
| 変異       | mutation                       | -       |
| 遺伝的変異 | genetic variant                | variant |
| 一塩基多型 | single nucleotide polymorphism | SNP     |
| 挿入       | insertion                      | INS     |
| 欠失       | deletion                       | DEL     |

## よくある誤解

- 変異という言葉は、必ず病気や悪い影響を意味するわけではありません。
- 変異が見つかっただけで、その変異が観察された現象の原因だと断定できるわけではありません。

## 重要用語

- 変異: [DNA](/glossary/dna/)配列に生じた変化。
- 遺伝的変異: [ゲノム](/glossary/genome/)配列に見られる個体間や細胞間の違い。
- SNP: 集団内で比較的よく見られる1塩基の違い。
- 変異検出: シーケンスデータなどから変異候補を見つける解析。
