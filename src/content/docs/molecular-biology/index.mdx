分子生物学は、生命現象をDNA、RNA、タンパク質などの分子の働きとして理解する分野です。BioLearnでは、基礎カテゴリで学んだ分子、細胞、DNA、RNA、タンパク質を土台に、核酸やアミノ酸などの部品から、遺伝情報が複製され、読み出され、細胞の中で働きに変わる流れまでを学びます。

## この分野で学ぶこと

- DNA複製、DNA損傷、DNA修復、組換え、セントラルドグマ、転写、RNAプロセシング、翻訳、遺伝子発現制御の関係
- 核酸、ヌクレオチド、塩基対、アミノ酸、タンパク質構造、フォールディング、酵素の基本
- DNA、RNA、タンパク質、遺伝子の知識を、情報の流れと発現制御としてつなげる見方
- クロマチン、ヌクレオソーム、DNAメチル化、ヒストン修飾を、遺伝子の読み出しやすさとして読む見方
- RNA-seqや差次的発現解析へ進む前提になる分子の言葉

## 目的別に選ぶ

## まず押さえる3つの考え方

1. セントラルドグマは、遺伝情報がRNAやタンパク質へ向かう基本的な見取り図です。
2. DNA複製はDNAを受け渡す過程で、DNA損傷・修復・組換えはDNAを維持する仕組みとして理解できます。
3. プロモーター、エンハンサー、転写因子、クロマチン状態、転写後制御は、遺伝子の使われ方を調節する仕組みです。

## 読む順番

まず基礎カテゴリでDNA、RNA、タンパク質、遺伝子を確認し、このページでは次の6セクションを順番に読みます。目的がはっきりしている場合は、必要なセクションから入ってもかまいません。

<a id="molecular-building-blocks"></a>

### 分子の部品を理解する

DNAやRNAを「核酸」、タンパク質を「アミノ酸がつながった分子」として読むための入口です。配列、塩基対、アミノ酸を先に押さえると、後の転写、翻訳、変異、酵素反応が理解しやすくなります。

読む記事: [核酸](/molecular-biology/nucleic-acids/) → [ヌクレオチド](/molecular-biology/nucleotide/) → [塩基対](/molecular-biology/base-pairing/) → [アミノ酸](/molecular-biology/amino-acid/)

<a id="information-flow"></a>

### 遺伝情報が使われる流れ

遺伝情報が保存され、写し取られ、加工され、タンパク質へ変換される流れを整理します。Figure読解やRNA-seqへ進む前に、どの段階の現象を見ているのかを分けられるようにします。

読む記事: [セントラルドグマ](/molecular-biology/central-dogma/) → [DNA複製](/molecular-biology/dna-replication/) → [転写](/molecular-biology/transcription/) → [RNAプロセシング](/molecular-biology/rna-processing/) → [スプライシング](/molecular-biology/splicing/) → [翻訳](/molecular-biology/translation/)

<a id="protein-function"></a>

### タンパク質が働く形になる

翻訳でできたアミノ酸配列が、立体構造をとり、細胞内で働く分子になる流れを見ます。Western blot、酵素反応、細胞シグナル伝達へ進む前の土台になります。

読む記事: [タンパク質構造](/molecular-biology/protein-structure/) → [タンパク質フォールディング](/molecular-biology/protein-folding/) → [酵素](/molecular-biology/enzyme/)

<a id="gene-regulation"></a>

### 発現を調節するしくみ

遺伝子が「いつ、どの細胞で、どれくらい」使われるかを調節するしくみを読みます。発現量、差次的発現解析、転写因子のFigureを読むときの前提になります。

読む記事: [遺伝子発現制御](/molecular-biology/gene-expression-regulation/) → [プロモーター](/molecular-biology/promoter/) → [エンハンサー](/molecular-biology/enhancer/) → [転写因子](/molecular-biology/transcription-factor/) → [非コードRNA](/molecular-biology/noncoding-rna/) → [miRNA](/molecular-biology/microrna/) → [転写後制御](/molecular-biology/post-transcriptional-regulation/)

<a id="chromatin-epigenetics"></a>

### DNAのしまわれ方とエピジェネティクス

DNAが細胞内でどのように折りたたまれ、読み出しやすさがどう変わるかを学びます。クロマチン状態、DNAメチル化、ヒストン修飾は、発現制御やゲノムブラウザの読み方にもつながります。

読む記事: [クロマチン](/molecular-biology/chromatin/) → [ヌクレオソーム](/molecular-biology/nucleosome/) → [エピジェネティクス](/molecular-biology/epigenetics/) → [DNAメチル化](/molecular-biology/dna-methylation/) → [ヒストン修飾](/molecular-biology/histone-modification/) → [クロマチンアクセシビリティ](/molecular-biology/chromatin-accessibility/)

<a id="dna-maintenance"></a>

### DNAを保つ・直すしくみ

DNAは複製されるだけでなく、損傷を受けたり修復されたり、組換えによって並び替わったりします。変異、ゲノム安定性、がんゲノミクスへ進む前に、DNAを維持するしくみを押さえます。

読む記事: [DNA損傷](/molecular-biology/dna-damage/) → [DNA修復](/molecular-biology/dna-repair/) → [組換え](/molecular-biology/recombination/)

- 転写と翻訳が、遺伝情報からタンパク質へ向かう流れのどこにあるか説明できる
