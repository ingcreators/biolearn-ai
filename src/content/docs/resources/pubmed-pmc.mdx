PubMed は生命科学・医学系文献を検索するためのデータベースです。PMC は本文が公開されている論文を読めるアーカイブです。

詳しい読み方は、論文読解演習の [PubMedの使い方](/papers/pubmed/) と [PMC論文の探し方](/papers/pmc/) でも扱います。

このページは、PubMed と PMC の使い分けを短く確認するための早見表です。読む論文を選ぶ流れを練習したい場合は、[最初に読む論文の選び方](/papers/how-to-choose-paper/) と [論文読解演習](/papers/) へ進みます。

他の早見表と使い分けたい場合は、[リファレンス](/resources/) に戻ります。

## 基本の流れ

1. PubMed でキーワードを検索します。
2. タイトルと Abstract で研究テーマを確認します。
3. Free full text や PMC のリンクがあれば本文へ進みます。
4. Figure、Methods、Results を行き来して、何が示されたのかを確認します。

## 読む順番の例

1. まずこのページで、PubMed、PMC、DOI、PMIDの違いを確認します。
2. [PubMedの使い方](/papers/pubmed/) で、検索結果から候補を絞ります。
3. [レビュー論文と原著論文の違い](/papers/review-vs-primary-paper/) で、全体像を知る論文か、データを読む論文かを分けます。
4. [最初に読む論文の選び方](/papers/how-to-choose-paper/) で、自分の目的に合う論文を選びます。
5. 本文が開ける場合は [PMC論文の探し方](/papers/pmc/) へ進み、Figure、Results、Methodsを確認します。
