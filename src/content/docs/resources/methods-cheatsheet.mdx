実験手法早見表では、論文の Methods や Figure legend に出てくる手法を、何を調べる方法なのかという観点で整理します。

| 手法           | 主に調べること                   | 関連記事                                                                            |
| -------------- | -------------------------------- | ----------------------------------------------------------------------------------- |
| PCR            | 特定のDNA領域を増幅する          | [PCRとは何か](/methods/what-is-pcr/)                                                |
| RNA-seq        | RNA由来の配列と発現量を調べる    | [RNA-seqとは何か](/bioinformatics/what-is-rna-seq/)                                 |
| 差次的発現解析 | 条件間で発現が変わる遺伝子を探す | [差次的発現解析とは何か](/bioinformatics/what-is-differential-expression-analysis/) |

## 読み方

Methods で手法名を見つけたら、「何を測ったのか」「どのサンプルを比較したのか」「対照は何か」を確認します。
