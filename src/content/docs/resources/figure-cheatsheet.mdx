description: 生命科学論文の Figure を読むときに確認する点をまとめた早見表です。
---

Figure を読むときは、図の種類にかかわらず、まず軸、条件、サンプル数、ばらつき、コントロール、統計表示を確認します。

| Figure        | 確認すること                             | 関連記事                                                     |
| ------------- | ---------------------------------------- | ------------------------------------------------------------ |
| Figure legend | 条件、反復、統計検定、略語               | [Figure legendの読み方](/figures/how-to-read-figure-legend/) |
| 棒グラフ      | 軸、平均、ばらつき、n数                  | [棒グラフの読み方](/figures/how-to-read-bar-plot/)           |
| qPCRプロット  | Ct値、相対発現量、対照遺伝子             | [qPCRプロットの読み方](/figures/how-to-read-qpcr-plot/)      |
| Western blot  | バンド、分子量、ローディングコントロール | [Western blotの読み方](/figures/how-to-read-western-blot/)   |
| Volcano plot  | fold change、p値、多重検定               | [Volcano plotの読み方](/figures/how-to-read-volcano-plot/)   |
| ヒートマップ  | 行・列、色の意味、クラスタ               | [ヒートマップの読み方](/figures/how-to-read-heatmap/)        |
