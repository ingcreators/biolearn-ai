陽性対照は「反応が出るはずの条件」、陰性対照は「反応が出ないはずの条件」です。

<LessonFigure
  src="/figures/positive-negative-control-concept.jpg"
  alt="陰性対照は低いシグナル、陽性対照は高いシグナル、試験条件はその間で評価されることを示す概念図"
  title="陽性対照と陰性対照で実験系を確認する"
  caption="反応が出る条件と出ない条件を置くことで、試験条件の結果を解釈しやすくします。"
/>

実験では、目的の処理やサンプルだけを見ても、実験系が正しく動いているか判断しにくいことがあります。そこで、反応が出ることを期待する陽性対照と、反応が出ないことを期待する陰性対照を置きます。

陽性対照が反応しない場合、実験系や検出方法に問題がある可能性があります。陰性対照で反応が出る場合、非特異的な反応、混入、背景シグナルなどを考える必要があります。

## なぜ重要か

Figureで差が見えても、陽性対照と陰性対照が適切でないと、その差が本当に目的の現象を反映しているのか判断しにくくなります。MethodsとFigure legendで、どの条件がどの対照として置かれているかを確認します。

## Figureで見る場所

陽性対照と陰性対照は、Figureのシグナル範囲を読む基準になります。

- 陰性対照で強いシグナルがある場合、背景や非特異的反応を疑います。
- 陽性対照で反応が弱い場合、検出系や試料処理の問題を考えます。
- 免疫染色やflow cytometryでは、陽性・陰性の境界やゲート設定に関わります。
- qPCRやWestern blotでは、目的の反応が期待どおり出るかを確認する助けになります。

対照がFigure内に見えない場合でも、MethodsやFigure legendに条件名として書かれていることがあります。

## 英語表記と略語

| 日本語名     | 英語名             | 略語 |
| ------------ | ------------------ | ---- |
| 陽性対照     | positive control   | -    |
| 陰性対照     | negative control   | -    |
| 背景信号     | background signal  | -    |
| 非特異的反応 | nonspecific signal | -    |

## よくある誤解

- 陰性対照は「何も入れない条件」とは限りません。
- 陽性対照があるだけで、目的の結論が証明されたわけではありません。
- 対照が本文で説明されず、Figureだけに書かれている場合もあります。

## 重要用語

- 陽性対照: 反応が出るはずの条件。
- 陰性対照: 反応が出ないはずの条件。
- 背景信号: 目的の反応とは別に見える信号。
- 非特異的反応: 目的の対象以外に由来する反応。
- [Figure legend](/glossary/figure-legend/): 陽性対照や陰性対照がどの条件として置かれているかを確認する説明文。
- [バイアス](/glossary/bias/): 対照設定、測定、解析、表示によって結果が一方向にずれる可能性。
