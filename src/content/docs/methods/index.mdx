実験手法では、生命科学の論文に出てくる測定や操作が「何を目的にしているのか」「どのような結果として現れるのか」を学びます。

## このページの役割

このページは、実験手法を分野として学び直すカテゴリトップです。論文を読んでいる途中で手法名だけを短く確認したい場合は、[実験手法早見表](/resources/methods-cheatsheet/) を使います。

| いまの状態                                           | 使う入口                                                               |
| ---------------------------------------------------- | ---------------------------------------------------------------------- |
| PCR、qPCR、Western blotなどを順に学び直したい        | このページの記事一覧                                                   |

| MethodsやFigure legendで出てきた手法名だけ確認したい | [実験手法早見表](/resources/methods-cheatsheet/)                       |
| Methods全体の読み方を練習したい                      | [Methodsの読み方](/papers/how-to-read-methods/)                        |
| サンプル、対照、反復、統計の確認漏れを減らしたい     | [Methods確認チェックリスト](/papers/methods-checklist/)                |
| 手法がFigureでどう見えるか確認したい                 | [論文Figureの読み方](/figures/)                                        |

## この分野で学ぶこと

- PCR、qPCR、Western blot などの基本的な実験手法の目的を説明できる
- 陽性対照、陰性対照、反復、サンプル調製の考え方を区別できる
- Methods と Figure legend で、条件や測定対象を確認できる

## おすすめの読む順番

初学者が順番に読む場合は、まずサンプルと対照で「何を何と比べるか」を押さえ、その後に核酸、シーケンス、タンパク質・細胞、遺伝子機能の順で進むと読みやすくなります。

| 順番 | まとまり                     | まず読む記事                                                                                                                                                                       |
| ---- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 実験の組み立て               | [サンプル](/methods/sample/) → [対照群](/methods/control/) → [陽性対照と陰性対照](/methods/positive-negative-control/)                                                             |
| 2    | 核酸を増やす・測る           | [PCR](/methods/pcr/) → [qPCR](/methods/qpcr/) → [RNA抽出](/methods/rna-extraction/) → [RT-qPCR](/methods/rt-qpcr/)                                                                 |
| 3    | シーケンスへつなぐ           | [シーケンシング](/methods/sequencing/) → [NGS](/methods/ngs/) → [ライブラリ調製](/methods/library-preparation/)                                                                    |
| 4    | タンパク質・細胞を見る       | [Western blot](/methods/western-blot/) → [蛍光顕微鏡](/methods/fluorescence-microscopy/) → [免疫染色](/methods/immunostaining/) → [フローサイトメトリー](/methods/flow-cytometry/) |
| 5    | 遺伝子機能を動かして確かめる | [CRISPR](/methods/crispr/) → [ノックアウト](/methods/knockout/) → [ノックダウン](/methods/knockdown/) → [過剰発現](/methods/overexpression/)                                       |

ローディングコントロール、抗体検証、ハウスキーピング遺伝子、FACS、ELISA、レポーターアッセイは、対応する基本手法を読んだあとに補足として読むと整理しやすくなります。
