実験手法では、生命科学の論文に出てくる測定や操作が「何を目的にしているのか」「どのような結果として現れるのか」を学びます。論文を読んでいる途中で手法名だけを短く確認したい場合は、[実験手法早見表](/resources/methods-cheatsheet/) を使います。

分子や細胞の前提があいまいな場合は、先に [生命科学の基礎](/fundamentals/) と [分子生物学](/molecular-biology/) を確認すると読みやすくなります。
