TitleとAbstractは、論文全体の地図です。研究の問い、対象、方法、主な結果を短時間でつかむために読みます。

Titleには、研究対象、現象、方法、主張の一部が含まれることがあります。まず、何についての論文なのか、どの生物、細胞、疾患、データを扱っているのかを拾います。

Abstractは、論文全体を短くまとめた文章です。多くの場合、背景、目的、方法、結果、結論が圧縮されています。読むときは、一文ずつ「背景」「問い」「方法」「結果」「解釈」に分けて印をつけると、論文の骨格が見えやすくなります。

ただし、Abstractは著者が強調したい結論を短くまとめたものです。実際にどこまで支持されているかは、Results、Figure、Methodsを読んで確認します。

## なぜTitleとAbstractを先に読むか

論文を読む前にTitleとAbstractで全体像をつかむと、途中で知らない用語に出会っても、何のための説明なのかを見失いにくくなります。

## 何を拾うか

| 見る場所 | 拾うこと                         | まだ判断しないこと                  |
| -------- | -------------------------------- | ----------------------------------- |
| Title    | 対象、現象、手法、主題           | 結論がどこまで強いか                |
| Abstract | 背景、問い、方法、結果、結論候補 | FigureやMethodsで根拠が十分かどうか |
| Keywords | 分野名、手法名、対象             | 論文全体の重要性                    |
| 最後の文 | 著者が強調したい結論             | 代替説明や限界がどれだけ残るか      |

## よくある誤解

- Abstractは論文全体の代わりではありません。根拠はResultsとFigureで確認します。
- Titleに強い表現があっても、実験や解析がどこまで支えているかは別に確認が必要です。
- Abstractの方法説明は短いため、実験条件の詳細はMethodsに戻ります。
