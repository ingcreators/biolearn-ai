DOIは、論文やデータなどを識別するための恒久的なIDです。URLが変わっても、同じ文献をたどる手がかりになります。

DOIやPMIDは論文を指定するための識別子です。本文を読めるかどうかや、研究内容の妥当性を示すものではありません。PubMed、PMC、DOI、PMIDの違いを短く確認したい場合は、[PubMed / PMC の使い分け](/resources/pubmed-pmc/) に戻ります。

DOIは digital object identifier の略です。生命科学論文では、論文ページ、PubMed、出版社ページ、参考文献リストなどに表示されることがあります。

DOIは、論文を引用したり、文献管理ツールに登録したり、同じ論文を探し直したりするときに役立ちます。タイトルが似た論文や、出版社ページのURLが変わった場合でも、DOIがあると識別しやすくなります。

DOIがあることは、論文の内容が正しいことを保証するものではありません。DOIは識別子であり、論文の質や解釈はResults、Methods、Figure、研究デザインを読んで判断します。

## DOIを確認する場面

| 場面             | DOIが役立つ理由                         | 注意すること                   |
| ---------------- | --------------------------------------- | ------------------------------ |
| 論文を引用する   | 同じ文献を正確に示しやすい              | DOIだけで内容を評価しない      |
| 文献管理する     | タイトル、著者、雑誌情報を取得しやすい  | 取得情報が正しいか確認する     |
| 論文を探し直す   | 出版社URLが変わっても文献をたどりやすい | 本文アクセス可否とは別に考える |
| Referencesを読む | 引用文献を特定しやすい                  | PMIDやPMC IDとは区別する       |

## よくある誤解

- DOIがある論文は、内容が必ず信頼できると考える。
- DOIとPubMed IDを同じものだと思う。
- 論文タイトルだけで十分で、DOIを確認しなくてよいと思う。
- DOIを本文への無料アクセスリンクそのものだと考える。
