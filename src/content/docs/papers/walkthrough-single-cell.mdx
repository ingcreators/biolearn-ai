## 架空ケース

ある研究では、条件Aと条件Bの細胞を[single-cell RNA-seq](/glossary/single-cell-rna-seq/)で解析し、細胞集団の構成と[遺伝子発現](/glossary/gene-expression/)の違いを調べたとします。論文の主張は「条件Bでは特定の細胞集団が増え、その集団で応答関連遺伝子が高い」です。

この主張を読むときは、[UMAP](/glossary/umap/)の見た目だけで結論を受け取らず、クラスタ、細胞型注釈、[マーカー遺伝子](/glossary/marker-gene/)、条件ごとの細胞数、差次的発現、Methodsの前処理を順に確認します。

## 読む順番

1. Abstractで、サンプル、条件、主な結論を拾います。
2. UMAPで、クラスタ数、条件ごとの重なり、外れた集団の有無を確認します。
3. マーカー遺伝子の図で、クラスタ名の根拠を確認します。
4. 条件ごとの細胞割合を見て、集団の増減が示されているかを確認します。
5. 差次的発現やpathway enrichmentで、主張に使われた遺伝子群を確認します。
6. Methodsで、細胞フィルタ、正規化、[バッチ効果](/glossary/batch-effect/)の扱い、[クラスタリング](/glossary/clustering/)条件、細胞型注釈の方法を確認します。

## Methodsで確認すること

| 項目           | 確認すること                                |
| -------------- | ------------------------------------------- |
| サンプル       | 条件ごとの個体数、細胞数、取得条件          |
| 品質管理       | 低品質細胞、ミトコンドリア比率、doublet処理 |
| 正規化         | 発現量の正規化、スケーリング、特徴量選択    |
| バッチ補正     | サンプル差や実験日の影響をどう扱ったか      |
| クラスタリング | 解像度、近傍グラフ、クラスタ名の根拠        |
| 比較解析       | 細胞単位かサンプル単位か、統計上の扱い      |

## 限界を読むポイント

single-cell解析では、細胞数が多く見えても、独立したサンプル数が少ないことがあります。細胞を大量に測っていることと、生物学的な反復が十分であることは同じではありません。

- UMAPやt-SNEの距離は、細胞系譜や因果関係を直接示すものではありません。
- クラスタ名は、marker gene、参照データ、著者の解釈に依存します。
- バッチ補正は必要なことが多い一方で、補正によって構造が変わる場合があります。
- 条件比較では、細胞数ではなくサンプル単位の反復がどれだけあるかを確認します。
- 細胞割合の変化は、採取条件、品質管理、細胞回収の偏りの影響を受けることがあります。
- 発現差やクラスタの違いだけでは、疾患機序や医療上の効果を直接示したことにはなりません。

Figureが魅力的に見えるほど、Methodsに戻ってサンプル、対照、バッチ、解析単位を確認します。結論は、表示された細胞の数ではなく、独立したサンプルと検証の強さに合わせて読みます。

## 3段階で読む演習

### 1. Methodsで確認する

single-cell論文では、細胞数だけでなく、独立したサンプルの数と処理の流れを確認します。

- 条件ごとの個体数、サンプル数、細胞数が分けて示されているか。
- QCで除外した細胞、低品質細胞、ダブレットの基準が書かれているか。
- バッチ補正や統合解析の方法が、条件差を消しすぎない形で説明されているか。
- クラスタリングの解像度と、細胞型アノテーションの根拠が示されているか。
- 統計比較の単位が、細胞なのかサンプルなのかを確認できるか。

細胞数が多く見えても、独立サンプルが少ない場合は、結論を控えめに読む必要があります。

### 2. Figureで確認する

次に、UMAPやマーカー遺伝子の図を、結論の種類ごとに読み分けます。

- UMAPでは、クラスタの位置よりも、条件ごとの混ざり方と外れた集団を見る。
- Marker plotでは、細胞型名がどの遺伝子に基づいているかを確認する。
- 細胞割合の棒グラフでは、細胞数だけでなくサンプル単位のばらつきを見る。
- クラスタ別DEGや経路解析では、比較対象と多重検定補正を確認する。

UMAPは強い印象を与えますが、それだけで細胞状態の原因や機能を決める図ではありません。

### 3. Discussionで言える範囲に戻す

Figureから言いやすいのは、「条件Bで特定の細胞集団が多く見える」「特定クラスタで関連遺伝子の発現が高い」という範囲です。

一方で、「細胞運命が直接変わった」「疾患や治療に直結する」といった表現は、追加の機能実験や独立検証が必要です。Discussionでは、細胞集団、発現変化、機能解釈が混ざっていないかを確認します。

### 自分で答える問い

- この論文の中心的な主張は、細胞割合の変化か、遺伝子発現の変化か。
- その主張はサンプル単位で再現性を確認できるか。
- UMAPの見た目だけでなく、どの補助Figureが結論を支えているか。

## よくある誤解

- UMAP上で距離が近いだけで、細胞状態が連続的につながっていると読む。
- クラスタ名を、マーカー遺伝子の確認なしに受け入れる。
- 細胞数が多い条件を、個体差やサンプル差を見ずに生物学的増加と読む。
- single-cell解析の差次的発現を、Methodsの統計単位を確認せずに読む。
