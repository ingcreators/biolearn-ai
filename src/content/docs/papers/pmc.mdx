PMCは、本文が公開されている生命科学・医学系論文を読めるアーカイブです。PubMedで見つけた論文の本文に進む入口になることがあります。

PubMedとPMCの違いを短く確認したい場合は、[PubMed / PMC の使い分け](/resources/pubmed-pmc/) に戻ります。このページでは、本文を開いたあとにFigure、Results、Methodsへ進む練習をします。

PMCでは、論文本文、Figure、表、Methods、ReferencesなどをWeb上で読めます。PubMedの検索結果からPMCリンクがある場合、本文に進めることがあります。

PMCで本文を読むときは、まずAbstractで全体像を確認し、Figure一覧やResultsへ進みます。Figureを見たら、Figure legend、Results本文、Methodsを行き来して、何を測り、何を比較しているかを確認します。

すべての論文がPMCで読めるわけではありません。論文の公開条件や出版社の方針によって、本文の入手方法は異なります。

## PMCで本文を開いたら見ること

| 見る場所   | 確認すること                       | 読み方                         |
| ---------- | ---------------------------------- | ------------------------------ |
| Abstract   | 研究の問い、方法、結果、結論の候補 | 全体像だけをつかむ             |
| Figure     | 何を測り、何を比較しているか       | legendとResultsへ戻る          |
| Results    | Figureの説明と主張の流れ           | Figureのパネルに対応づける     |
| Methods    | サンプル、条件、対照、解析、統計   | Figureの解釈に必要な部分を読む |
| References | 背景論文、手法論文、次に読む文献   | 目的に応じてたどる             |

## よくある誤解

- PubMedにある論文は、必ずPMCにもあると思う。
- PMCで読める論文だけが重要だと考える。
- Figureだけを見て、MethodsやResultsを確認しない。
- 本文が読めることと、内容が正しいことを同じに考える。
