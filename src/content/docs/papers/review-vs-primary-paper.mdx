レビュー論文は分野の知識を整理する論文、原著論文は新しい実験や解析結果を報告する論文です。読む目的に応じて使い分けます。

論文種別の意味だけを短く確認したい場合は、重要用語から用語集へ戻ります。このページでは、どちらを先に読むか、どこまで根拠を確認するかを練習します。

レビュー論文（review article）は、多くの先行研究をまとめ、分野の背景、主要な考え方、未解決の問題を整理します。初めてのテーマでは、レビュー論文から読むと全体像をつかみやすくなります。

原著論文（primary research article）は、著者自身の実験や解析に基づく新しい結果を報告します。Figure、Methods、Resultsを読んで、どのデータがどの主張を支えているかを確認します。

レビュー論文は便利ですが、著者の整理や解釈が入っています。重要な主張を深く確認したいときは、引用されている原著論文へ戻ります。

## どちらを先に読むか

| 目的                               | 向いている論文 | 読み方                                       |
| ---------------------------------- | -------------- | -------------------------------------------- |
| 分野の全体像をつかみたい           | レビュー論文   | 用語、背景、代表的な研究、未解決の問いを拾う |
| 実際のデータを読めるようになりたい | 原著論文       | Figure、Results、Methodsを対応づける         |
| 次に読む論文を探したい             | レビュー論文   | Referencesから重要な原著論文を選ぶ           |
| 主張の根拠を確かめたい             | 原著論文       | Methods、対照、反復、統計、限界を確認する    |

## よくある誤解

- レビュー論文だけ読めば、根拠の確認も十分だと思う。
- 原著論文を読むときに、Abstractだけで結論を判断する。
- レビュー論文の図を、元データそのものだと考える。
- 原著論文のMethodsを確認せず、Figureの意味を決めてしまう。
