論文読解演習は、ここまで学んだ生命科学の基礎、実験手法、統計、Figure読解を使って、論文を読む練習をするカテゴリです。最初から全文を精読するのではなく、論文の構造をつかみ、FigureとResultsを見て、必要なMethodsやDiscussionへ戻る読み方を身につけます。

順番に身につけたい場合は [論文を読めるようになる](/paths/paper-reading/) を使います。このページでは、いま読んでいる論文のどこで止まったか、または何を練習したいかからセクションを選びます。

## つまずいたら戻る

Figureの読み方で止まった場合は [論文Figureの読み方](/figures/) に戻ります。実験条件や対照で止まった場合は [実験手法](/methods/) を確認します。p値、n数、反復、限界の読み方で止まった場合は [統計・研究デザイン](/statistics/) に戻ります。論文を読む順番から練習したい場合は [論文を読めるようになる](/paths/paper-reading/) を使います。
