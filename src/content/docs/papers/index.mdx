論文読解演習では、生命科学論文を読むときに、研究目的、実験設計、Figure、Methods、Results を順番に確認する練習をします。

## この分野で学ぶこと

- Abstract と Introduction から研究の問いをつかむ
- Methods からサンプル、実験、解析条件を確認する
- Results と Figure を行き来して、何が示されたのかを読む
- Discussion の主張と限界を分けて読む

## 今後追加する演習

- Figure legend から実験条件を拾う練習
- Methods からサンプル数と解析条件を確認する練習
- Results の主張を Figure に戻って確認する練習
