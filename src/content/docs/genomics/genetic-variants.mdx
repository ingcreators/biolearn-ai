遺伝的変異は、個体や細胞の間で見られるゲノム配列の違いです。

ゲノム配列には、個人差や細胞ごとの差があります。1塩基だけが異なる場合もあれば、塩基が挿入されたり欠失したりする場合もあります。こうした違いを遺伝的変異と呼びます。

遺伝的変異にはさまざまな種類があります。1塩基の違いであるSNP、短い配列の挿入や欠失、より大きな構造変化などがあります。変異が遺伝子の中にあるのか、調節領域にあるのか、タンパク質のアミノ酸配列を変えるのかによって、考えるべき影響は異なります。

変異があるからといって、必ず大きな影響があるとは限りません。多くの変異は中立的か、影響が小さい場合があります。一方で、特定の条件では機能に影響する変異もあります。重要なのは、変異の存在と意味を分けて考えることです。

疾患や形質との関係を考えるには、統計的証拠、機能実験、集団頻度などを合わせて慎重に解釈します。この教材では、個人の診断や治療判断ではなく、ゲノム配列の違いを学ぶための基礎概念として扱います。

## なぜ重要か

[遺伝的変異](/glossary/genetic-variant/)は、[ゲノム](/glossary/genome/)を個体差や細胞差として理解するための基本概念です。同じ生物種でも配列は完全に同じではなく、その違いが形質、進化、疾患研究、集団解析の手がかりになることがあります。

ただし、変異を見つけることと、その意味を決めることは別です。変異の位置、頻度、[遺伝子](/glossary/gene/)や調節領域との関係、機能実験の証拠を合わせて考える必要があります。

## 具体例

ある位置で、多くの人はAを持つのに、一部の人はGを持つことがあります。このような1塩基の違いは[SNP](/glossary/snp/)として扱われることがあります。

別の例として、数塩基が挿入されたり、欠失したりする変異があります。タンパク質をコードする領域で挿入や欠失が起こると、読み枠やアミノ酸配列に影響する場合がありますが、常に大きな影響があるとは限りません。

## よく混同される概念

- 変異とSNP: SNPは変異の一種で、集団内で比較的よく見られる1塩基の違いを指します。
- 変異と病的変化: 変異は配列の違いを指す言葉で、必ず病気や悪い影響を意味するわけではありません。
- 相関と原因: ある変異と形質が統計的に関連しても、その変異が直接の原因とは限りません。

## 論文や実験ではどう出てくるか

遺伝的変異は、全ゲノムシーケンシング、エクソーム解析、GWAS、バリアントコールなどで登場します。論文では、変異のゲノム上の位置、アリル頻度、影響予測、集団間の頻度差、機能実験の結果として示されることがあります。

## 英語表記と略語

| 日本語名   | 英語名                         | 略語    |
| ---------- | ------------------------------ | ------- |
| 遺伝的変異 | genetic variant                | variant |
| 一塩基多型 | single nucleotide polymorphism | SNP     |
| 挿入       | insertion                      | INS     |
| 欠失       | deletion                       | DEL     |

## よくある誤解

- 変異という言葉は必ず悪い意味ではありません。
- ある変異が見つかっただけで、個人の健康状態や将来を断定できるわけではありません。

## 重要用語

- 遺伝的変異: [ゲノム](/glossary/genome/)配列に見られる個体間や細胞間の違い。
- 一塩基多型: [SNP](/glossary/snp/)とも呼ばれる、集団内で比較的よく見られる1塩基の違い。
- 挿入: 配列の一部に塩基が追加される変化。
- 欠失: 配列の一部の塩基が失われる変化。
