BioLearn は、生命科学の基礎から始めて、生命科学論文の Figure、Methods、Results を根拠に戻って読めるようになるための日本語教材サイトです。

順番に学びたい場合は [ラーニングパス](/paths/) から今の目的に合う入口を選びます。特定の分野から学びたい場合は [分野別カテゴリ](/categories/) から進めます。途中で用語や確認点だけ見直したい場合は、[用語集](/glossary/) や [リファレンス](/resources/) を使います。

## 最初の3ステップ

1. [生命科学とは何か](/fundamentals/life-science/) を読み、BioLearnで扱う範囲をつかみます。
2. [ラーニングパス](/paths/) から、順番に読む入口を選びます。
3. 特定の分野から学びたい場合は、[分野別カテゴリ](/categories/) から探します。
