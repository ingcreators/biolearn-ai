BioLearn では、生命科学を「分子」「細胞」「ゲノム」「データ解析」から「論文Figureの読み方」、さらに「論文全体の読み方」へ進む流れで学びます。

- 高校生物を学び直したい人
- 医療・ヘルスケア・創薬領域に関心がある人
- 情報系エンジニアとして生命科学に入門したい人
- 生命科学論文を読めるようになりたい人

最初に読む記事は [生命科学とは何か](/fundamentals/life-science/) です。すべてを一度に覚える必要はありません。まずは言葉に慣れ、次に「分子が細胞で働き、その情報をゲノムとデータから読み解き、最後に論文Figureや論文本文として示された結果を読む」という流れをつかみます。

BioLearn全体の章立ては [学習ロードマップ](/roadmap/) にまとめています。順番に練習したい場合は [ラーニングパス](/paths/) から始め、途中で確認点だけ見直したい場合は [リファレンス](/resources/) を使います。

## 使い方

- はじめて学ぶ場合は、[基礎から学ぶ](/paths/foundations/) から始めます。
- すでに基礎用語に慣れている場合は、[Figureを読めるようになる](/paths/figure-reading/) から始めても構いません。
- 論文全体を読みたい場合は、先にFigure読解の感覚を作ってから [論文を読めるようになる](/paths/paper-reading/) へ進みます。
- 特定の記事だけを探したい場合は、分野別カテゴリや [用語集](/glossary/) を使います。
- 各記事の「確認問題」で説明できない用語があれば、[用語集](/glossary/) で確認します。

## 最短ルート

まず [生命科学とは何か](/fundamentals/life-science/) と [細胞とは何か](/fundamentals/cell/) で全体像を作ります。その後、DNA、RNA、タンパク質、遺伝子発現を確認し、実験手法、バイオインフォマティクス、統計、Figure読解へ進みます。

章ごとの詳しい順番は [学習ロードマップ](/roadmap/) にあります。記事を順番に並べたルートで進みたい場合は、[基礎から学ぶ](/paths/foundations/)、[Figureを読めるようになる](/paths/figure-reading/)、[論文を読めるようになる](/paths/paper-reading/) を使います。
