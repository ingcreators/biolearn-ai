BioLearn は、生命科学の基礎から始めて、最終的に生命科学論文の Figure、Methods、Results を読めるようになるための日本語教材サイトです。

- 高校生物を学び直したい人
- 医療・ヘルスケア・創薬領域に関心がある人
- 情報系エンジニアとして生命科学に入門したい人
- 生命科学論文を読めるようになりたい人

最初に読む記事は [生命科学とは何か](/fundamentals/life-science/) です。すべてを一度に覚える必要はありません。まずは「細胞、DNA、RNA、タンパク質、遺伝子、ゲノム」を混同せずに置き、そこから実験手法、データ解析、統計表示、論文 Figure、論文本文へ広げていきます。

BioLearn 全体の構成は [学習ロードマップ](/roadmap/) にまとめています。順番に練習したい場合は [ラーニングパス](/paths/) から始め、途中で確認点だけ見直したい場合は [リファレンス](/resources/) を使います。

## 使い方

- はじめて学ぶ場合は、[基礎を固める](/paths/foundations/) から始めます。
- すでに基礎用語に慣れている場合は、目的に合わせて [細胞のしくみを理解する](/paths/cell-mechanisms/)、[実験・統計を確認する](/paths/methods-statistics/)、[オミクス解析を読む](/paths/omics-analysis/)、または [Figureを読む](/paths/figure-reading/) から始めても構いません。
- 論文全体を読みたい場合は、先に Figure と Methods に戻る感覚を作ってから [論文を読む](/paths/paper-reading/) へ進みます。
- 特定の記事だけを探したい場合は、分野別カテゴリや [用語集](/glossary/) を使います。
- 各記事の「確認問題」で説明できない用語があれば、[用語集](/glossary/) で確認します。

## 最短ルート

まず [生命科学とは何か](/fundamentals/life-science/) と [細胞とは何か](/fundamentals/cell/) で全体像を作ります。その後、DNA、RNA、タンパク質、遺伝子、ゲノムを確認し、実験手法、バイオインフォマティクス、統計、Figure読解へ進みます。

記事を順番に並べたルートで進みたい場合は、[ラーニングパス](/paths/) から、基礎、細胞、実験・統計、オミクス解析、Figure、論文のどこから入るかを選びます。全体の見取り図は [学習ロードマップ](/roadmap/) にあります。
