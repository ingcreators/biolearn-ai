BioLearn は、生命科学の基礎から始めて、生命科学論文の Figure、Methods、Results を根拠に戻って読めるようになるための日本語教材サイトです。

まずは [学習ロードマップ](/roadmap/) で全体像を確認し、その後 [ラーニングパス](/paths/) から今の目的に合う順番を選びます。途中で用語や確認点だけ見直したい場合は、[用語集](/glossary/) や [リファレンス](/resources/) を使います。

## 最初の3ステップ

1. [生命科学とは何か](/fundamentals/life-science/) を読み、BioLearnで扱う範囲をつかみます。
2. [学習ロードマップ](/roadmap/) で、ラーニングパスと分野別カテゴリの使い分けを確認します。
3. [ラーニングパス](/paths/) から、順番に読む入口を選びます。
