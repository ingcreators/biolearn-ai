## 日本語名

CNV plot

## 英語名

copy number variation plot

## 略語

CNV plot

## まず一言でいうと

CNV plotは、ゲノム上の位置に沿ってDNA領域のコピー数が増えているか減っているかを示す図です。

## もう少し詳しく

染色体位置、基準線、セグメント、ノイズ、サンプル比較を合わせて読みます。点の揺れだけでなく、連続した領域として変化しているかを確認します。

## なぜ重要か

コピー数変異の候補領域を視覚的に確認できます。ただし、解析方法、データ品質、比較対象を見ずに意味を断定しません。

## よく混同される用語

- コピー数変異: ゲノム領域のコピー数が増減する変化です。
- ゲノム座標: ゲノム上の位置を表す表記です。
