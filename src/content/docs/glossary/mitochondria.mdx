# ミトコンドリア

ミトコンドリアは、細胞のエネルギー代謝に深く関わる細胞小器官です。

## もう少し詳しく

ミトコンドリアは外膜と内膜を持ち、内膜のひだであるクリステではエネルギー代謝に関わる反応が進みます。細胞が使いやすいエネルギーの形であるATPの産生にも関わります。

ミトコンドリアは独自のDNAを持ちますが、ミトコンドリアで働くタンパク質の多くは核ゲノムにコードされています。

## なぜ重要か

ミトコンドリアを理解すると、細胞の代謝、細胞状態、single-cell QCで出てくるミトコンドリア由来RNA割合などを読みやすくなります。
