# リソソーム

リソソームは、細胞内の不要な分子や取り込まれた物質の分解に関わる細胞小器官です。

## もう少し詳しく

リソソーム内部は酸性に保たれており、その環境で働く分解酵素を持ちます。外から取り込まれた物質や、細胞内で不要になった成分がリソソームで分解され、材料の再利用につながります。

オートファジーでは、細胞内の成分が膜で包まれ、最終的にリソソームと融合して分解されます。

## なぜ重要か

リソソームを理解すると、細胞が分子や細胞小器官を作るだけでなく、分解し、更新し、再利用する仕組みを考えやすくなります。
