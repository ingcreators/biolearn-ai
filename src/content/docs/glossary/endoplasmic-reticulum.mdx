# 小胞体

小胞体は、タンパク質や脂質の合成、加工、輸送に関わる膜構造です。

## もう少し詳しく

粗面小胞体にはリボソームが付着し、分泌タンパク質や膜タンパク質の一部の合成に関わります。滑面小胞体は、脂質合成やカルシウムの貯蔵などに関わります。

小胞体で作られた一部のタンパク質や脂質は、小胞を介して[ゴルジ体](/glossary/golgi-apparatus/)へ運ばれ、さらに加工や仕分けを受けます。

## なぜ重要か

小胞体を理解すると、タンパク質が作られたあと、どこで折りたたまれ、加工され、輸送されるのかを細胞内の場所として追いやすくなります。
