## 日本語名

遺伝子セット

## 英語名

gene set

## 略語

-

## まず一言でいうと

遺伝子セットは、共通の機能、経路、条件などでまとめられた遺伝子の集合です。

## もう少し詳しく

GSEAやpathway enrichmentでは、個々の遺伝子ではなく、あらかじめ定義された遺伝子セット単位で偏りを調べます。

## なぜ重要か

遺伝子セットの定義によって解析結果の意味が変わるため、どのデータベースやバージョンを使ったかを確認する必要があります。

## よく混同される用語

- パスウェイ: 生物学的な経路や反応のまとまりです。遺伝子セットとして表されることがあります。
- 遺伝子リスト: 解析で選んだ候補遺伝子の一覧で、事前定義された遺伝子セットとは区別します。
