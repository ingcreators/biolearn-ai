# ゴルジ体

ゴルジ体は、タンパク質や脂質を加工し、行き先に応じて仕分ける細胞小器官です。

## もう少し詳しく

ゴルジ体には、[小胞体](/glossary/endoplasmic-reticulum/)から運ばれてきたタンパク質や脂質が届きます。そこで糖鎖修飾などの加工を受け、細胞膜、細胞外、リソソームなどへ向かう流れに仕分けられます。

ゴルジ体は単なる通過点ではなく、分子の成熟や行き先の決定に関わります。

## なぜ重要か

ゴルジ体を理解すると、分泌タンパク質、膜タンパク質、受容体の局在、細胞内輸送のFigureを読みやすくなります。
