## 日本語名

リファレンスゲノム

## 英語名

reference genome

## まず一言でいうと

リファレンスゲノムは、配列解析やゲノム表示で基準として使う代表的なゲノム配列です。

## もう少し詳しく

実験で得た配列は、リファレンスゲノムに対応づけることで、どの染色体のどの位置に由来するかを考えやすくなります。リファレンスは「その生物の完全な一個体」ではなく、解析の座標系として使う標準的な配列です。

## なぜ重要か

同じデータでも、使うリファレンスゲノムやバージョンが変わると、座標や注釈との対応が変わることがあります。論文やデータベースを読むときは、どのリファレンスを使ったかを確認します。

## よく混同される用語

- [ゲノム](/glossary/genome/): ある生物が持つ遺伝情報の全体。
- [ゲノム座標](/glossary/genomic-coordinate/): リファレンス上の位置を表す表記。
- [ゲノムアノテーション](/glossary/genome-annotation/): リファレンス上の領域に意味づけを加えた情報。
