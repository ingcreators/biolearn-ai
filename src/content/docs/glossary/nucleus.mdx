# 核

核は、真核細胞で多くのDNAを収め、遺伝情報の管理やRNAの合成に関わる区画です。

## もう少し詳しく

核は核膜に囲まれており、内部ではDNAが[クロマチン](/glossary/chromatin/)として整理されています。[転写](/glossary/transcription/)やDNA複製、DNA修復など、遺伝情報に関わる多くの過程が核内で起こります。

核内には核小体という領域もあり、リボソームRNAの産生などに関わります。核と核小体は同じものではありません。

## なぜ重要か

核を理解すると、DNA、染色体、クロマチン、転写因子の核移行、遺伝子発現の変化を細胞内の場所として整理できます。
