# 細胞骨格

細胞骨格は、細胞の形、動き、分裂、細胞内輸送を支えるタンパク質ネットワークです。

## もう少し詳しく

代表的な細胞骨格には、アクチンフィラメント、中間径フィラメント、微小管があります。アクチンは細胞の形の変化や移動、微小管は細胞内輸送や細胞分裂、中間径フィラメントは力学的な安定性に関わります。

細胞骨格は固定された骨ではなく、細胞の状態に応じて組み替わる動的な構造です。

## なぜ重要か

細胞骨格を理解すると、細胞形態、細胞移動、細胞分裂、細胞内輸送、免疫染色画像を読みやすくなります。
