# Project brief

## 概要

BioLearnは、生命科学を初学者が体系的に学ぶための日本語教材サイトです。対象分野は、分子生物学、細胞生物学、ゲノミクス、バイオインフォマティクス、論文Figureの読み方です。

## 対象読者

- 高校生物を学び直したい社会人
- 医療・ヘルスケア・創薬領域に関心がある人
- 情報系エンジニアで生命科学に入門したい人
- バイオインフォマティクスを学びたい初学者
- 生命科学論文を読めるようになりたい人

## MVPの目的

MVPでは、学習ロードマップ、章立て教材、用語集、確認問題、教材用MDXコンポーネントを備えた静的サイトを構築します。過度な機能追加よりも、読みやすく保守しやすい教材基盤を優先します。

## 非対象

- 医療上の診断、治療、個別の健康助言
- 著作権が不明な画像や図版の利用
- 学術的に裏づけの弱い断定的な主張

## 成功条件

- `npm install` が成功する
- `npm run dev` でローカル起動できる
- `npm run build` が成功する
- サイドバーからカテゴリと初期ページへ移動できる
- MDX内で教材用コンポーネントが使える
